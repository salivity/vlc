How to Make VLC Resume Video Playback

VLC Media Player can automatically resume video playback from the exact position where you last closed it. While older legacy releases required third-party extensions, all modern versions of VLC feature a built-in tool that tracks your progress across audio and video files. This guide explains how the resume feature works, how to configure it to always play from where you left off without prompting, and how to manage the setting across Windows, macOS, and mobile devices.

How to Enable Automatic Resume on Windows and Linux

By default, VLC displays a prompt asking if you want to resume playback whenever you reopen a partially watched file. You can configure VLC to resume playback automatically without asking:

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P).
  3. Ensure the Interface tab is selected at the top.
  4. Locate the Continue playback? dropdown menu.
  5. Change the setting from Ask to Always.
  6. Click Save at the bottom of the window and restart VLC to apply the changes.

How to Enable Automatic Resume on macOS

Mac users can configure the same automatic playback behavior through the macOS preferences panel:

  1. Open VLC on your Mac.
  2. Click on VLC media player in the menu bar at the top-left of the screen and select Settings... (or press Cmd + ,).
  3. In the Interface section, locate the Continue playback? setting.
  4. Set the option to Always.
  5. Click Save to confirm your selection.

How Resume Playback Works on Android and iOS

The mobile versions of VLC handle resume playback natively:

  • Android: VLC automatically remembers your playback position. You can customize this behavior by opening the app, navigating to More > Settings > Video, and adjusting the Resume played video setting to Always, Ask, or Never.
  • iOS: VLC for iOS automatically preserves your position for any media file stored in the local app library. Tapping a previously watched video will automatically pick up from the last recorded timestamp.

Important Considerations

For VLC to successfully resume playback, keep the following requirements in mind:

  • File Location: The file name and file path must remain identical. If you rename, move, or delete the video, VLC will treat it as a new file and start from the beginning.
  • Playback History: VLC relies on its internal media history to remember playback positions. If you disable playback history or clear your "Recently Played" list, all saved timestamps will be reset.
  • Duration Threshold: Very short media clips or files played within the first or last few seconds typically do not trigger the resume feature.
