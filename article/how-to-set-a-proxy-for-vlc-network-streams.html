How to Set a Proxy for VLC Network Streams

Routing network streams through a proxy server in VLC Media Player allows you to bypass network restrictions, protect your IP address, and access geo-restricted content. This guide explains how to manually configure an HTTP or SOCKS proxy directly within VLC's advanced settings on desktop platforms like Windows, macOS, and Linux.

Step 1: Open Advanced Preferences

  1. Launch VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P on Windows/Linux, Cmd + , on macOS).
  3. At the bottom-left corner of the Preferences window, locate the Show settings section.
  4. Switch the selection from Simple to All to reveal the full preferences tree.

Step 2: Configure the Proxy Settings

  1. In the left-hand navigation pane, expand the Input / Codecs category.
  2. Expand the Access modules sub-category.
  3. Scroll down and click on HTTP(S).
  4. In the main panel on the right, locate the HTTP proxy input field.
  5. Enter your proxy server address using the standard URL format:
    • Standard HTTP Proxy: http://proxy_address:port (e.g., http://192.168.1.100:8080)
    • Authenticated Proxy: http://username:password@proxy_address:port
    • SOCKS5 Proxy: socks5://proxy_address:port (or socks5://username:password@proxy_address:port)
  6. Click the Save button at the bottom right.
  7. Close and restart VLC Media Player to ensure the changes take effect.

Step 3: Test the Network Stream

  1. Click on Media in the top menu and choose Open Network Stream... (or press Ctrl + N).
  2. Enter the URL of the media stream you want to play.
  3. Click Play.

VLC will now route the requested stream through the specified proxy server. If the stream fails to load, verify your proxy IP, port, and authentication credentials, and ensure your firewall permits outbound connections from VLC.
