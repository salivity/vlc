How to Remove Metadata in VLC While Transcoding

Transcoding a video in VLC Media Player allows you to re-encode the stream while discarding embedded metadata such as camera models, GPS coordinates, author details, and creation dates. This guide provides step-by-step instructions for stripping metadata from your video files using both the VLC graphical interface and the VLC command-line interface.

Method 1: Strip Metadata Using the VLC Graphical Interface

To ensure all metadata is removed during conversion, you must clear the existing metadata tags before initiating the transcode process.

  1. Open VLC Media Player.
  2. Go to Media in the top menu and select Convert / Save (or press Ctrl + R on Windows/Linux, Cmd + Shift + S on macOS).
  3. In the File tab, click Add... to select the video file you want to process.
  4. Click the Convert / Save button at the bottom.
  5. In the Convert dialog window, select your target format from the Profile dropdown menu (e.g., Video - H.264 + MP3 (MP4)).
  6. Click the wrench icon (Edit selected profile) next to the dropdown menu:
    • Go to the Audio codec and Video codec tabs to confirm the "Keep original track" options are unchecked. Re-encoding the streams forces VLC to write a fresh container without carrying over original stream-level properties.
    • Click Save.
  7. Click Browse next to the Destination file field to choose a destination folder and a new name for the output file.
  8. Click Start to begin transcoding.

Note: To ensure container-level tags (such as Title, Artist, and Copyright) are completely erased prior to conversion, open the video in VLC, press Ctrl + I (Tools > Media Information), delete all text in the fields, click Save Metadata, and then perform the conversion steps above.

Method 2: Strip Metadata Using the VLC Command Line

The command-line interface allows you to completely bypass metadata passthrough during the transcoding process by specifying pure stream outputs.

  1. Open your system's terminal (Command Prompt/PowerShell on Windows, Terminal on macOS/Linux).
  2. Run the following command (adjust paths and filenames as needed):

Windows (Command Prompt):

"C:\Program Files\VideoLAN\VLC\vlc.exe" -I dummy "input.mp4" --sout="#transcode{vcodec=h264,vb=2000,acodec=mp3,ab=192}:standard{access=file,mux=mp4,dst='output_clean.mp4'}" vlc://quit

macOS:

/Applications/VLC.app/Contents/MacOS/VLC -I dummy input.mp4 --sout='#transcode{vcodec=h264,vb=2000,acodec=mp3,ab=192}:standard{access=file,mux=mp4,dst=output_clean.mp4}' vlc://quit

Linux:

vlc -I dummy input.mp4 --sout='#transcode{vcodec=h264,vb=2000,acodec=mp3,ab=192}:standard{access=file,mux=mp4,dst=output_clean.mp4}' vlc://quit

Why This Removes Metadata:

  • -I dummy: Runs VLC without loading the graphical user interface.
  • --sout: Directly routes the raw audio and video through the specified encoders (vcodec=h264, acodec=mp3).
  • Fresh Muxing: The mux=mp4 option encapsulates the newly encoded elementary streams into a brand-new container, omitting all custom tags, EXIF markers, location records, and historical metadata present in the original container.
