How to Password Protect VLC Web Interface

VLC Media Player features an integrated HTTP server that allows you to control media playback remotely across your local network using any web browser. To prevent unauthorized users on your network from hijacking playback, VLC requires an HTTP password to enable the remote control functionality. This guide outlines the exact steps to enable the web interface, configure your authentication password, and verify the login prompt from your browser.

Step 1: Open Advanced Preferences

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P on Windows/Linux).
  3. In the bottom-left corner of the Preferences window, locate the Show settings section.
  4. Select the All radio button to switch from simple view to advanced settings.

Step 2: Set the HTTP Password

  1. In the left-hand navigation pane, expand the Interface section.
  2. Expand Main interfaces, then click on Lua.
  3. On the right panel, scroll down to the Lua HTTP section.
  4. In the Password field, type the password you wish to use for logging into the web interface.
  5. Leave the Source directory field blank unless you are hosting a custom web skin.

Step 3: Enable the Web Interface

  1. Still in the left pane under Interface, click directly on Main interfaces.
  2. On the right panel, check the box labeled Web (HTTP remote control interface).
  3. Click the Save button in the lower-right corner to apply your changes.
  4. Close and restart VLC Media Player so the HTTP server initializes with your new configuration.

Step 4: Verify the Login

  1. Open any web browser on your computer.
  2. Navigate to http://localhost:8080 or http://127.0.0.1:8080. If accessing from another device on the same network, replace localhost with the host machine's local IP address (e.g., http://192.168.1.50:8080).
  3. An authentication dialog will appear. Leave the Username field blank.
  4. Enter the password you created in Step 2 into the Password field and submit.

Once authenticated, the browser will load the full VLC web control dashboard.
