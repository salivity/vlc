How to Change VLC Snapshot Directory

By default, VLC Media Player saves video snapshots directly to your operating system's default Pictures folder. If you prefer keeping your captures organized in a dedicated project folder or a different drive, you can quickly redirect where VLC stores these image files. This guide provides a straightforward walkthrough on how to change the default snapshot directory and customize file output settings in VLC Media Player.

Changing the Snapshot Directory

  1. Open VLC Preferences: Launch VLC Media Player. Click on Tools in the top menu bar and select Preferences, or press Ctrl + P on Windows (Cmd + , on macOS).
  2. Access Video Settings: In the Preferences window, select the Video icon from the navigation bar.
  3. Locate the Video Snapshots Section: Scroll to the bottom of the Video settings page to find the section labeled Video snapshots.
  4. Choose a New Folder: Click the Browse... button next to the Directory field. Browse your system, select the folder where you want your images saved, and click Select Folder (or Open on macOS).
  5. Save Your Changes: Click the Save button in the lower-right corner of the window to apply your new settings. All future snapshots will now be saved to this folder.

Optional Snapshot Adjustments

While in the Video snapshots menu, you can also modify how VLC labels and formats your captures:

  • Prefix: Enter a custom text prefix in the Prefix box to replace the default "vlcsnap-" name.
  • Sequential Numbering: Check the box for Sequential numbering if you prefer numbered files (e.g., snapshot-00001) instead of the default date-and-time timestamps.
  • Format: Click the Format dropdown menu to switch between PNG, JPG, or TIFF formats depending on your preference for compression or image quality.
