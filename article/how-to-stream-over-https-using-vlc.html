How to Stream Over HTTPS Using VLC

This guide explains how to configure VLC Media Player to broadcast media across a secure HTTPS connection. By establishing a TLS/SSL-encrypted stream, you prevent unauthorized interception and ensure data integrity while transmitting video or audio over local or public networks. The following sections cover generating necessary security certificates, configuring VLC’s streaming output, and connecting client devices to your secure feed.

Step 1: Generate TLS/SSL Certificates

VLC requires a valid certificate and private key to encrypt traffic over HTTPS. For internal networks or testing, generate a self-signed certificate using OpenSSL:

  1. Open your terminal or command prompt.
  2. Run the following command to generate a certificate and private key valid for one year: 
    openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout vlc_stream.key -out vlc_stream.crt
  3. Complete the certificate prompts (Common Name should match your server's IP address or domain name).
  4. Note the absolute file paths to vlc_stream.key and vlc_stream.crt.

Step 2: Configure VLC via the Command-Line Interface

Configuring HTTPS directly through VLC's command-line interface provides the most reliable way to define SSL parameters and output streams.

Run the following command, replacing the file paths and input source with your own:

vlc -vvv "input_video.mp4" --sout '#transcode{vcodec=h264,vb=2000,acodec=mp3,ab=128}:standard{access=https,mux=ts,dst=:8443/stream}' --http-cert="/path/to/vlc_stream.crt" --http-key="/path/to/vlc_stream.key"
  • --sout: Defines the stream output chain, transcoding settings, and encapsulation.
  • access=https: Forces the output module to use HTTPS instead of unencrypted HTTP.
  • dst=:8443/stream: Specifies the listening port (8443) and the resource path (/stream).
  • --http-cert and --http-key: Direct VLC to your cryptographic files.

To stream a live capture device (such as a webcam) instead of a file, replace "input_video.mp4" with v4l2:///dev/video0 on Linux or dshow:// on Windows.

Step 3: Configure VLC via the Graphical User Interface

If you prefer using the graphical interface:

  1. Open VLC and navigate to Tools > Preferences.
  2. In the bottom-left corner, select All under "Show settings" to access advanced options.
  3. In the left panel, navigate to Stream output > Access output > HTTPS.
  4. In the fields provided, enter the absolute paths to your Certificate file (.crt) and Private key file (.key). Click Save.
  5. Go to Media > Stream... (or press Ctrl + S).
  6. Click Add to select your media file or navigate to the Capture Device tab for live video. Click Stream.
  7. In the Stream Output wizard, click Next.
  8. Under Destination Setup, select HTTP (or HTTPS if listed in your VLC build) from the dropdown, click Add, set the port to 8443, and specify a path (e.g., /stream).
  9. Choose an appropriate transcoding profile (such as Video - H.264 + MP3 (TS)) and click Stream.

Step 4: Access the Secure Stream from a Client

  1. Open VLC on the client machine.
  2. Select Media > Open Network Stream... (or press Ctrl + N).
  3. Enter the full URL of the streaming host: 
    https://<SERVER-IP-ADDRESS>:8443/stream
  4. Click Play.

Note: If you are using a self-signed certificate, VLC or the client operating system may prompt you to accept or trust the certificate before playback begins.
