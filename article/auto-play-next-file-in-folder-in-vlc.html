Auto-Play Next File in Folder in VLC

By default, VLC Media Player stops after finishing a single media file, requiring manual interaction to start the next one. You can configure VLC to automatically play every subsequent video or audio track in a directory without manually building or saving playlist files. This guide details how to adjust VLC's native settings and playback methods to achieve seamless, continuous playback straight from any folder.

Method 1: Play the Entire Folder Directly

The quickest built-in way to play through a directory without manually saving a playlist file is to point VLC to the directory itself:

  1. Open VLC Media Player.
  2. Click Media on the top menu bar and select Open Folder... (or press Ctrl + F on Windows / Cmd + O on macOS).
  3. Select the folder containing your media files and click Select Folder.

VLC will automatically load all playable files in that directory in alphabetical order and transition to the next file as each finishes. You can also achieve this by simply dragging an entire folder and dropping it directly into an open VLC window.

Method 2: Configure Advanced Playlist Preferences

To ensure VLC automatically advances through queued folder items without stopping:

  1. Click Tools > Preferences (or press Ctrl + P).
  2. In the bottom-left corner under Show settings, change the radio button from Simple to All.
  3. In the left-hand navigation tree, click on Playlist.
  4. In the right panel, verify the following options:
    • Uncheck Play and exit (if checked, VLC terminates after one file).
    • Uncheck Play and pause (if checked, VLC pauses at the end of each track).
    • Check Automatically prepare next item in playlist.
    • Change Subdirectory behavior to Expand to include files located inside subfolders.
  5. Click Save and restart VLC.

Method 3: Enable Single-Instance Enqueue Mode

If you frequently launch files by double-clicking them in your operating system's file manager, you can instruct VLC to append subsequent selections into the current queue rather than interrupting playback:

  1. Go to Tools > Preferences.
  2. Keep the view set to Simple and remain on the Interface tab.
  3. Scroll down to the Playlist and Instances section.
  4. Check Use only one instance when started from file manager.
  5. Check Enqueue items into playlist in one instance mode.
  6. Click Save.

With these settings active, selecting multiple files in a folder and pressing Enter or right-clicking to open them will automatically queue them sequentially in a single VLC session.
