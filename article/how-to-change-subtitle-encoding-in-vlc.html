How to Change Subtitle Encoding in VLC

When loading legacy subtitle formats like SRT or SUB in VLC Media Player, text can often appear garbled, broken, or full of strange symbols due to an encoding mismatch between the file and the player. This guide provides a direct, step-by-step walkthrough on how to override VLC's default text encoding settings so your legacy subtitles render clearly and correctly on screen.

Step-by-Step Guide to Overriding Subtitle Encoding

  1. Open VLC Preferences

    • Launch VLC Media Player.
    • On Windows or Linux, click on Tools in the top menu bar and select Preferences (or press Ctrl + P).
    • On macOS, click VLC in the menu bar and select Settings (or press Cmd + ,).

  2. Access Subtitle Settings

    • In the Preferences window, select the Subtitles / OSD (On-Screen Display) tab located on the left or top panel.
    • Ensure that Simple settings are selected at the bottom-left corner of the window (under "Show settings").

  3. Modify the Default Encoding

    • Look for the Subtitle effects section.
    • Find the dropdown menu labeled Default encoding. By default, this is usually set to Universal (UTF-8) or System Default.
    • Click the dropdown and select the encoding format that corresponds to your subtitle file's language or origin. Common options include:
      • Western European (Windows-1252 / ISO-8859-1): Ideal for older English, Spanish, French, and German subtitles.
      • Eastern/Central European (Windows-1250 / ISO-8859-2): For Polish, Czech, Hungarian, and Romanian subtitles.
      • Cyrillic (Windows-1251): For Russian, Ukrainian, and Bulgarian subtitles.
      • Greek (Windows-1253): For Greek subtitles.
      • Hebrew (Windows-1255): For Hebrew subtitles.
      • Arabic (Windows-1256): For Arabic subtitles.

  4. Save and Apply

    • Click the Save button at the bottom right of the Preferences window.
    • Close VLC Media Player and reopen it to ensure the changes take effect.
    • Play your video and reload the subtitle file to verify that the text renders correctly.

Additional Tip

If you are unsure of the file's original encoding, open the subtitle file in a basic text editor (such as Notepad on Windows or TextEdit on macOS) and check the "Save As" dialogue to see the currently detected encoding, or cycle through the relevant regional Windows/ISO encodings in VLC until the characters display properly.
