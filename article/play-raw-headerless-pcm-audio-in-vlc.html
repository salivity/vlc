Play Raw Headerless PCM Audio in VLC

VLC media player supports playing back raw PCM audio files that lack headers, but it cannot play them automatically out of the box. Because headerless PCM files contain only raw sample data without metadata defining the sample rate, channel count, or bit depth, VLC requires you to manually specify these parameters before playback. This guide explains how to configure and play raw PCM streams in VLC using both the command-line interface and the advanced graphical settings.

Why Raw PCM Requires Manual Configuration

Standard audio formats like WAV or AIFF wrap PCM data in containers that include header metadata. This header instructs media players on how to interpret the binary stream—such as whether the audio is 44,100 Hz, 16-bit, stereo, or little-endian. Headerless raw PCM files (often saved with extensions like .pcm, .raw, or .bin) omit this data completely. When VLC attempts to play a raw file without prior instructions, it cannot guess the correct layout, resulting in silence, static, or an immediate playback error.

Playing Raw PCM via the Command Line

The most reliable method to play raw PCM files in VLC is through the command line or terminal. By passing specific flags, you instruct VLC's raw audio demuxer on how to read the data.

Use the following command structure:

vlc --demux=rawaud --rawaud-channels=2 --rawaud-samplerate=44100 --rawaud-fourcc=s16l your_file.raw

Key parameters include:

  • --demux=rawaud: Forces VLC to use its raw audio demuxer instead of attempting automatic container detection.
  • --rawaud-channels: Sets the number of audio channels (e.g., 1 for mono, 2 for stereo).
  • --rawaud-samplerate: Defines the audio sample rate in Hertz (e.g., 44100, 48000, or 96000).
  • --rawaud-fourcc: Specifies the sample format and endianness. Common codes include:
    • s16l: Signed 16-bit Little-Endian (standard CD quality format)
    • s16b: Signed 16-bit Big-Endian
    • s24l: Signed 24-bit Little-Endian
    • f32l: 32-bit floating point Little-Endian
    • u8: Unsigned 8-bit

Playing Raw PCM via the Graphical Interface

You can also configure VLC to handle raw files through its interface preferences, though this setting will apply globally until reverted.

  1. Open VLC and navigate to Tools > Preferences.
  2. At the bottom of the window, under Show settings, select All to switch to the advanced preferences view.
  3. In the left-hand menu, expand Input / Codecs, then expand Demuxers, and select Audio demuxer.
  4. In the settings panel, locate the Raw audio demuxer options.
  5. Set the Audio channels, Sample rate, and Audio format (FourCC) to match the specifications of your raw file.
  6. Click Save.
  7. Go to Media > Open File, select your raw PCM file, and VLC will decode the audio using the parameters you defined.

Remember to reset your demuxer preferences back to default when finished, as leaving raw audio demuxing forced can prevent standard media formats from opening properly.
