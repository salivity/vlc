Extract EIA-608 Captions from ATSC Streams in VLC

While VLC Media Player can decode and display EIA-608 closed captions during playback of an ATSC transport stream (.ts file), it cannot reliably extract and save these captions into an external subtitle file format like SRT. Because EIA-608 data is embedded directly into the video stream rather than stored as a separate subtitle track, VLC's standard conversion and stream-saving tools fail to isolate the text. To extract and save these captions, dedicated extraction software like CCExtractor is required.

VLC's Playback vs. Extraction Capabilities

VLC includes built-in support for ATSC broadcasts and can render embedded EIA-608 and CEA-708 closed captions on screen. You can view them by navigating to Subtitle > Sub Track during playback and selecting the closed caption stream (often labeled as "Closed Captions 1").

However, VLC’s "Convert / Save" feature lacks the parsing logic to strip EIA-608 data from the video frames and convert it to standalone formats such as SubRip (.srt), WebVTT (.vtt), or Scenarist (.scc). When attempting to convert the file using VLC's subtitle export options, the resulting file will typically contain no subtitle track or result in an empty text file.

Why VLC Fails to Export EIA-608

EIA-608 captions are not multiplexed as standard subtitle streams. Instead, they are embedded directly inside the MPEG-2 or H.264 video layer as Picture User Data (SEI NAL units in H.264 or user_data packets in MPEG-2).

VLC treats subtitles during conversion as distinct, multiplexed streams. Because the 608 captions reside inside the video packets themselves, VLC's demuxer passes them through as raw video data rather than extracting the byte pairs needed to reconstruct the text.

The Solution: Using CCExtractor

The definitive, open-source tool for extracting EIA-608 captions from ATSC transport streams is CCExtractor. It is designed specifically to parse transport stream packets, locate the embedded user data, and convert the closed caption data into clean subtitle files.

To extract EIA-608 captions using CCExtractor:

  1. Download and install CCExtractor.
  2. Open your command-line interface (Terminal or Command Prompt).
  3. Run the following command:
ccextractor input_stream.ts -o output_subtitles.srt

CCExtractor will automatically scan the ATSC stream, decode the EIA-608 byte pairs, align the timestamps, and export a fully synchronized .srt file. This output file can then be loaded back into VLC alongside the original video via Subtitle > Add Subtitle File.
