Can VLC Display Lyrics Embedded in MP3 Files?

VLC Media Player does not natively support the automatic display of lyrics embedded inside the ID3 tags of MP3 files during playback. While VLC can decode almost any audio format, it lacks a dedicated on-screen interface to parse and render standard unsynchronized (USLT) or synchronized (SYLT) ID3 lyric tags. However, users can still manually view embedded metadata through the player's information panel, load external subtitle-style lyric files, or install third-party Lua extensions to read song lyrics.

Native ID3 Lyric Limitations in VLC

When an MP3 contains embedded lyrics, they are typically stored within the ID3v2 metadata container under specific frames. VLC ignores these frames during standard playback and will not project them onto the screen like subtitles.

You can occasionally view raw text if the tagging software placed the lyrics into standard fields like the "Comments" tag:

  1. Open the MP3 file in VLC.
  2. Press Ctrl + I (Windows/Linux) or Cmd + I (macOS) to open the Current Media Information window.
  3. Check the General tab to see if lyrics appear under the Comments section.

If the lyrics are stored properly in dedicated lyric frames (USLT), VLC will usually leave this field blank.

The Best Workaround: Using External .LRC Files

Because VLC treats synchronized lyrics identical to video subtitles, the most reliable way to display lyrics in real-time is using an external .lrc file:

  1. Create or download an .lrc file that matches the song.
  2. Place the .lrc file in the exact same directory as your MP3 file.
  3. Rename the .lrc file so it shares the exact same name as the MP3 file (for example, song.mp3 and song.lrc).
  4. Play the track in VLC. The player will automatically load the lyrics as a subtitle track and display them across the bottom of the playback window.

You can also manually load an .lrc file during playback by navigating to Subtitle > Add Subtitle File... from the top menu bar.

Adding Lyric Support via VLC Extensions

For users who want VLC to fetch or display lyrics automatically without creating .lrc files manually, VLC supports community-made add-ons:

  1. Go to Tools > Plugins and extensions.
  2. Search the add-on directory for extensions such as Lyrics Finder or browse the official VLC add-ons website for lyrics-fetching Lua scripts.
  3. Install the extension and restart VLC. These scripts generally fetch lyrics online based on the artist and title tags, displaying them in a separate floating dialog window.
