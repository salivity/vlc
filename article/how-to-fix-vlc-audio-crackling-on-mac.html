How to Fix VLC Audio Crackling on Mac

Audio crackling, popping, or stuttering in VLC Media Player on macOS is typically caused by audio module conflicts, buffer underruns, or sample rate mismatches between the media file and your system settings. This guide outlines direct, effective solutions to eliminate unwanted audio distortion in VLC, covering player preference adjustments and macOS system-level audio configurations.

1. Change the Audio Output Module

By default, VLC automatically selects an audio output module, which can sometimes cause synchronization and processing issues on macOS.

  1. Open VLC and go to VLC media player in the top menu bar, then select Settings (or press Cmd + ,).
  2. Click the Audio tab at the top.
  3. In the bottom-left corner, change Show settings from Simple to All.
  4. In the left sidebar, navigate to Audio > Output modules.
  5. Click the dropdown menu next to Audio output module and change it from Default to AUHAL audio output (or try CoreAudio if AUHAL is already selected).
  6. Click Save and restart VLC.

2. Increase File Caching (Buffer Size)

If VLC cannot buffer the audio stream quickly enough—especially when playing high-resolution or high-bitrate files—it can cause audible popping.

  1. Open VLC Settings (Cmd + ,).
  2. Set Show settings to All in the bottom-left corner.
  3. In the left sidebar, click on Input / Codecs.
  4. Scroll down to the Advanced section on the right.
  5. Increase File caching (ms) from the default 300 or 1000 to 2000 or 3000.
  6. If playing from a local network or external drive, also increase Network caching (ms) or Disc caching (ms) accordingly.
  7. Click Save and restart VLC.

3. Adjust macOS Audio MIDI Setup

A mismatch between VLC’s playback sample rate and your Mac's output hardware settings frequently causes static and popping noises.

  1. Open Finder, go to Applications > Utilities, and open Audio MIDI Setup.
  2. Select your active output device (e.g., MacBook Pro Speakers, Headphones, or your external audio interface) from the left sidebar.
  3. Look at the Format settings on the right.
  4. Set the sample rate to 44,100 Hz (44.1 kHz) or 48,000 Hz (48.0 kHz), with a 2-channel 24-bit or 16-bit integer depth. Most media files use 48 kHz or 44.1 kHz.
  5. Test playback in VLC to see if the crackling stops.

4. Disable Time Stretching

VLC uses an audio time-stretching algorithm to keep audio in pitch when playback speed changes. This feature can introduce audio artifacts even during normal playback.

  1. Open VLC Settings (Cmd + ,).
  2. Click the Audio tab (in Simple view).
  3. Uncheck the option labeled Enable time stretching audio.
  4. Click Save and restart playback.

5. Reset VLC Preferences

Corrupted configuration files from previous versions or settings changes can degrade audio performance.

  1. Open VLC Settings (Cmd + ,).
  2. In the bottom-left corner, click Reset All (or Reset Preferences).
  3. Confirm the prompt and restart VLC.
