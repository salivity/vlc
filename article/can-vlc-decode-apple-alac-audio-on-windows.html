Can VLC Decode Apple ALAC Audio on Windows?

VLC Media Player can natively decode Apple Lossless Audio Codec (ALAC) files on Windows without requiring any third-party plugins, iTunes, or external codec packs. This article details how VLC handles the ALAC format, supported containers, high-resolution playback capabilities, and troubleshooting steps if you encounter issues playing your files.

Native ALAC Support in VLC

VLC natively supports ALAC across all major platforms, including Windows 10 and Windows 11. The player relies on the built-in FFmpeg multimedia framework (specifically the libavcodec library), which includes an open-source decoder for ALAC.

Because VLC is completely standalone, you do not need to install Apple software, such as QuickTime or iTunes, to play ALAC tracks.

Supported Containers and Bit Depths

ALAC audio is rarely stored as a raw stream; it is almost always wrapped inside a container. VLC handles the standard file formats used for ALAC:

  • M4A (.m4a): The standard MP4 audio container used by Apple for lossless tracks.
  • CAF (.caf): The Core Audio Format commonly generated by macOS audio production software.

VLC easily handles CD-quality audio (16-bit/44.1 kHz) as well as high-resolution audio streams up to 24-bit/192 kHz. It decodes the compressed lossless stream directly into an uncompressed PCM signal and passes it to your Windows audio output.

How to Play ALAC Files in VLC

  1. Open VLC Media Player.
  2. Drag and drop your .m4a or .caf file directly into the VLC window, or use Media > Open File... (Ctrl + O).
  3. To verify that the file is decoding properly as ALAC, go to Tools > Codec Information (Ctrl + I) while the track is playing. Under the Codec tab, the audio stream will display Apple Lossless Audio Codec (alac).

Troubleshooting Playback Issues

If VLC fails to play an ALAC file on Windows, the issue usually stems from container corruption or audio output misconfiguration rather than codec incompatibility:

  • Update VLC: Ensure you are running the latest stable release of VLC to benefit from current FFmpeg decoder patches.
  • Corrupted Metadata: Files ripped or converted using non-standard software may contain malformed MP4 headers. Re-muxing or re-converting the track using tools like FFmpeg or Foobar2000 can fix the file header.
  • Audio Output Module: If the track plays silently, navigate to Tools > Preferences > Audio and change the Output module from Automatic to DirectX audio output or WaveOut audio output, then restart VLC.
