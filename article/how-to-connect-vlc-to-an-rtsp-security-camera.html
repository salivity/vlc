How to Connect VLC to an RTSP Security Camera

Connecting VLC Media Player to an RTSP (Real-Time Streaming Protocol) security camera feed allows you to monitor live surveillance video directly from your computer without proprietary software. This guide provides a straightforward, step-by-step walkthrough to help you find your camera's network information, construct the correct RTSP URL, and stream the live video feed using VLC.

1. Gather Your Camera Details

Before opening VLC, collect the following information from your camera's web interface or mobile app:

  • IP Address: The local IP address assigned to the camera (e.g., 192.168.1.50).
  • Port: The default RTSP port is usually 554. If unchanged, it is often optional in the URL.
  • Username and Password: The login credentials for your camera's stream.
  • Stream Path: The internal path specific to your camera's brand and model (e.g., /h264Preview_01_main for Reolink, /Streaming/Channels/101 for Hikvision, or /cam/realmonitor?channel=1&subtype=0 for Dahua). Consult your camera manufacturer's manual to find your exact path.

2. Construct the RTSP URL

Assemble your details into the standard RTSP URL structure:

rtsp://username:password@IP_address:554/stream_path

Example:
rtsp://admin:mypassword123@192.168.1.50:554/h264Preview_01_main

3. Open the Stream in VLC

  1. Launch VLC Media Player.
  2. Click on Media in the top menu bar and select Open Network Stream (or press Ctrl + N on Windows / Cmd + N on macOS).
  3. In the Network tab, enter your complete RTSP URL into the Please enter a network URL field.
  4. Click Play (or Open on macOS).

VLC will connect to the camera and begin displaying the live video feed after a brief buffering period.

4. Troubleshooting Connection Issues

  • Video Lag or Gray Artifacts: Go to Tools > Preferences, select All under Show settings (bottom-left), navigate to Input / Codecs, scroll to Network caching (ms), and increase the value from 1000 to 2000 or 3000.
  • Connection Drops: In the same advanced settings under Input / Codecs > Demuxers > RTP/RTSP, check the box for Use RTP over RTSP (TCP) to prevent packet loss over unstable Wi-Fi networks.
  • Authentication Errors: If VLC fails to authenticate when credentials are included in the URL, enter the URL without the username and password (rtsp://IP_address:554/stream_path) and input your credentials when VLC's authentication pop-up appears.
