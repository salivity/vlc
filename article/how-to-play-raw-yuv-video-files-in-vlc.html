How to Play Raw YUV Video Files in VLC

VLC Media Player does support playing raw, uncompressed YUV video files, but it cannot play them automatically through standard double-clicking or drag-and-drop actions. Because raw YUV files contain only raw pixel samples without a container header to specify resolution, frame rate, or chroma format, VLC requires you to explicitly define these parameters before playback will work.

Why Raw YUV Needs Extra Configuration

Standard video formats (such as MP4, MKV, or AVI) include metadata that informs the media player about the video's width, height, aspect ratio, frame rate, and color space. Raw YUV files (.yuv) completely lack this metadata. If you attempt to open a raw YUV file directly in VLC without providing these details, VLC either fails to open the file or displays garbled noise.

Method 1: Using the Command Line (Recommended)

The fastest and most reliable way to play a raw YUV stream is by launching VLC from your system terminal or command prompt with the rawvid demuxer parameters.

Open Terminal (macOS/Linux) or Command Prompt (Windows) and enter the command using your specific video specifications:

vlc --demux rawvid --rawvid-width 1920 --rawvid-height 1080 --rawvid-chroma I420 --rawvid-fps 30 video.yuv

Key Command Parameters:

  • --demux rawvid: Forces VLC to use its raw video demuxer instead of attempting automatic container detection.
  • --rawvid-width: The horizontal resolution in pixels (e.g., 1920, 1280, 3840).
  • --rawvid-height: The vertical resolution in pixels (e.g., 1080, 720, 2160).
  • --rawvid-chroma: The pixel layout and chroma subsampling format. Common values include:
    • I420 (YUV 4:2:0 planar, standard)
    • YV12 (YUV 4:2:0 planar, inverted chroma planes)
    • NV12 (YUV 4:2:0 semi-planar)
    • UYVY or YUY2 (YUV 4:2:2 packed)
  • --rawvid-fps: The playback frame rate (e.g., 24, 30, 60).

Method 2: Configuring the Graphical Interface (GUI)

If you prefer using the graphical interface, you can permanently set the raw video defaults within VLC’s preferences:

  1. Open VLC and navigate to Tools > Preferences (or VLC > Settings on macOS).
  2. At the bottom of the window, locate Show settings and select the All radio button to access advanced settings.
  3. In the left sidebar, expand Input / Codecs and click on Demuxers.
  4. Change the Demux module dropdown from Automatic to Raw video demuxer.
  5. In the left sidebar under Demuxers, click directly on Raw video.
  6. Enter your video's width, height, chroma format (FourCC), and frame rate into the corresponding fields.
  7. Click Save.

Once saved, open your .yuv file directly in VLC.

Note: Remember to revert the Demux module back to "Automatic" when you are finished, otherwise VLC will attempt to treat all future media files as raw video streams.
