Integrate VLC in Python Using python-vlc

VLC Media Player can be fully integrated into a Python script using the python-vlc module, which provides complete bindings for the underlying LibVLC engine. This article explains how the integration works, covers the essential system prerequisites, details the installation process, and provides a clear code example to play media files directly from Python.

Prerequisites and How It Works

The python-vlc package is not a standalone media player; it relies on ctypes to interface directly with libvlc, the core engine behind VLC Media Player. For the module to function, VLC must be installed on your operating system. Crucially, the bitness of your Python interpreter must match the bitness of your VLC installation (e.g., 64-bit Python requires 64-bit VLC).

Installation

To integrate VLC into your project, install the binding using pip:

pip install python-vlc

Basic Playback Example

Playing a local media file or network stream requires only a few lines of code:

import vlc
import time

# Create a VLC instance and a media player object
player = vlc.MediaPlayer("path/to/media/file.mp4")

# Start playback
player.play()

# Keep the script alive while the media plays
time.sleep(1) # Allow player to initialize
while player.is_playing():
    time.sleep(1)

Key Playback Controls

The MediaPlayer object provides direct access to standard media controls:

  • Pause and Resume: player.pause()
  • Stop Playback: player.stop()
  • Volume Control: player.audio_set_volume(80) (takes an integer from 0 to 100)
  • Track Time: player.get_time() returns the current playback position in milliseconds.
  • Seek: player.set_time(30000) jumps to the 30-second mark.

Advanced Integration and GUIs

Beyond background playback, python-vlc supports embedding video output into graphical user interfaces. By passing a native window handle (such as an HWND on Windows or an XID on Linux) to methods like player.set_hwnd() or player.set_xwindow(), video can be rendered directly inside frameworks like Tkinter, PyQt, PySide, or wxPython. The module can also stream content from remote URLs, manage playlists, and extract track metadata.
