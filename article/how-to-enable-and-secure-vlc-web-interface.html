How to Enable and Secure VLC Web Interface

The VLC media player includes a built-in HTTP server that allows you to control media playback remotely from any web browser on your network. This guide provides a clear walkthrough on how to enable this remote control feature, configure a strong password to block unauthorized access, edit host permissions for extra security, and access the interface from another device.

Step 1: Enable the Web Interface

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P on Windows / Cmd + , on macOS).
  3. In the bottom-left corner of the Preferences window, look for Show settings and select the All radio button to switch from Simple to Advanced preferences.
  4. In the left sidebar, navigate to Interface > Main interfaces.
  5. Check the box next to Web (HTTP remote control interface).

Step 2: Set a Password to Secure the Interface

VLC requires a password to activate the web interface. Without a password, the web server will fail to start for security reasons.

  1. In the advanced preferences menu, look at the left sidebar under Main interfaces and click on Lua.
  2. Scroll to the Lua HTTP section on the right side.
  3. Locate the Password field and enter a strong, unique password.
  4. (Optional) You can change the default Source directory if you host custom web controls, but the default path works best for standard use.
  5. Click Save in the bottom-right corner.
  6. Completely close and restart VLC for the changes to take effect.

Step 3: Restrict IP Access with the Hosts File

By default, VLC only permits connections from the local machine (localhost). To control VLC from another device on your local network while blocking untrusted devices, you must configure the .hosts file.

  1. Navigate to the VLC installation directory on your computer:
    • Windows: C:\Program Files\VideoLAN\VLC\lua\http\ (or Program Files (x86))
    • macOS: /Applications/VLC.app/Contents/MacOS/share/lua/http/
    • Linux: /usr/share/vlc/lua/http/
  2. Open the file named .hosts in a plain text editor with administrator privileges.
  3. To allow access from your entire local subnet, locate the private network section and uncomment your subnet range by removing the # symbol. For example:
    • For standard home routers: remove the # before 192.168.1.0/24 or 192.168.0.0/24.
    • To allow only a single specific device (e.g., your smartphone), add its specific local IP on a new line (such as 192.168.1.50).
  4. Save and close the file.

Step 4: Access the Web Interface

  1. On the host computer or an allowed network device, open a web browser.
  2. In the address bar, type:
    • From the same machine: http://localhost:8080
    • From another device: http://[HOST-IP-ADDRESS]:8080 (replace [HOST-IP-ADDRESS] with the local IP address of the computer running VLC).
  3. When prompted for credentials, leave the Username field empty and enter the password you created in Step 2.
  4. Press Enter to load the remote control dashboard.

Best Practices for Network Safety

  • Never port-forward port 8080: Do not expose the VLC web interface directly to the public internet via router port-forwarding, as the interface is not designed for public-facing threats.
  • Use a VPN for remote access: If you need to control playback outside of your home network, set up a local VPN (such as WireGuard or OpenVPN) to connect back to your local network securely.
