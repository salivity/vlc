How to Set VLC Parental Controls

VLC Media Player is an open-source, versatile media player, but it does not feature a native, password-protected parental control system or an automatic explicit content filter. Because VLC simply plays whatever local files or streams you direct it to, managing what younger viewers can access requires a combination of tweaking VLC’s internal privacy settings and using operating system-level controls. This guide covers how to clear playback history, disable automatic metadata retrieval, and restrict access to explicit files on your computer.

Understand VLC's Limitations

VLC does not analyze video files for explicit language, violence, or adult content, nor does it read MPAA or TV rating tags to block media automatically. To filter explicit content, you must control the files accessible on your device and configure VLC so it does not log or display previously viewed mature content.

Step 1: Disable Playback History and Recent Items

To prevent children from seeing or opening recently played mature media through VLC's menus:

  1. Open VLC Media Player.
  2. Navigate to Tools > Preferences (or press Ctrl + P on Windows, Cmd + , on Mac).
  3. Select the Interface tab.
  4. Under the Privacy / Network Interaction section, uncheck Save recently played items.
  5. Click Save.

To clear existing history immediately:

  • On Windows: Click Media on the top menu, hover over Open Recent Media, and select Clear.
  • On macOS: Click File > Open Recent > Clear Menu.

Step 2: Turn Off Automatic Metadata and Album Art Fetching

VLC can automatically download media information and album covers from the internet, which can occasionally display inappropriate cover art:

  1. Go to Tools > Preferences.
  2. Select the Interface tab.
  3. Under Privacy / Network Interaction, find Album art download policy.
  4. Change the dropdown menu to Manual download only or Never download album art.
  5. Click Save.

Step 3: Restrict File Access at the Operating System Level

Since VLC lacks user accounts or password locks, the most effective way to filter content is via your computer's operating system permissions.

On Windows:

  1. Move all explicit or mature media files into a single, dedicated folder.
  2. Right-click the folder and select Properties.
  3. Go to the Security tab and click Edit.
  4. Create a standard (non-administrator) Windows user account for your child.
  5. In the permissions list, select the child's account and check Deny for Read and Read & Execute permissions.

On macOS:

  1. Set up a standard or managed account for your child via System Settings > Users & Groups.
  2. Place restricted media in your private user folder (/Users/[YourUsername]/Movies), which standard user accounts cannot access by default.
  3. Use Screen Time settings to restrict application access if you prefer to block VLC altogether during unsupervised hours.

Step 4: Password-Protect Video Archives

If you share a single computer profile:

  1. Compress mature video files into an encrypted archive using software like 7-Zip or WinRAR.
  2. Set a strong password with AES-256 encryption.
  3. Extract files only when you intend to watch them, ensuring children cannot launch them directly through VLC.
