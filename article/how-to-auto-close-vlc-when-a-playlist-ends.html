How to Auto-Close VLC When a Playlist Ends

VLC Media Player includes a built-in configuration option that automatically closes the program once the current playlist reaches its end. This feature is particularly useful for falling asleep to audio or video, running scheduled playback, or saving system resources. This guide walks you through enabling this setting permanently via the preferences menu and running it temporarily via command-line options.

Method 1: Enable "Play and Exit" via Preferences

To configure VLC to automatically shut down after completing a playlist, follow these steps:

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P on Windows/Linux; Cmd + , on macOS).
  3. In the bottom-left corner of the Preferences window, locate the Show settings section and select the All radio button to switch to the advanced settings view.
  4. In the left-hand navigation tree, click on Playlist.
  5. In the right pane, locate the option labeled Play and exit.
  6. Check the box next to Play and exit.
  7. Click the Save button at the bottom right.
  8. Restart VLC Media Player for the changes to take full effect.

From now on, whenever VLC completes the last item in the playlist, the application will terminate automatically. To revert this behavior, return to this menu, uncheck Play and exit, and save your settings.

Method 2: Launch with Command Line (One-Time Use)

If you only want VLC to close automatically for a specific session without altering your permanent preferences, you can launch VLC using a command-line flag:

  • Windows: Open Command Prompt and enter:

    vlc --play-and-exit "C:\path\to\your\media_or_playlist"

  • macOS: Open Terminal and enter:

    /Applications/VLC.app/Contents/MacOS/VLC --play-and-exit /path/to/your/media_or_playlist

  • Linux: Open Terminal and enter:

    vlc --play-and-exit /path/to/your/media_or_playlist

VLC will launch, play through the specified files or playlist, and automatically exit upon completion without saving this behavior for future manual launches.
