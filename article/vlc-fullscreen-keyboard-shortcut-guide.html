VLC Fullscreen Keyboard Shortcut Guide

This guide covers the default keyboard shortcuts used to enter and exit fullscreen mode in VLC Media Player across different operating systems. Learn the primary hotkeys for Windows, Linux, and macOS, how to leave fullscreen view, and how to change these settings to suit your personal preferences.

The Default Shortcuts

The primary keyboard shortcut to enter fullscreen mode depends on your operating system:

  • Windows and Linux: Press the F key.
  • macOS: Press Command + Control + F (or Command + F depending on your VLC version).

How to Exit Fullscreen Mode

To return to standard windowed mode, use any of the following methods:

  • Press the F key again.
  • Press the Esc (Escape) key.
  • Double-click anywhere on the video playback screen.

Mouse Shortcut

If you prefer using a mouse, you can enter and exit fullscreen mode by quickly double-clicking the primary playback window.

How to Customize the Fullscreen Shortcut

If you want to assign a different key for fullscreen playback, you can modify the hotkey settings in VLC:

  1. Open VLC Media Player.
  2. Navigate to Tools > Preferences (or press Ctrl + P on Windows/Linux, or Command + , on Mac).
  3. Select the Hotkeys tab at the top or bottom of the preferences window.
  4. Scroll through the list to find the Fullscreen action.
  5. Double-click the hotkey field next to Fullscreen, press your desired key or combination, and click Save.
  6. Restart VLC for the changes to take full effect.
