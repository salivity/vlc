How to Control VLC Remotely with a Web Browser

VLC Media Player includes a built-in HTTP interface that allows you to control media playback remotely using any standard web browser on a computer, smartphone, or tablet. By enabling this native feature and setting a password, you can pause, play, adjust volume, and manage playlists across your local network without installing third-party software.

Step 1: Enable the VLC Web Interface

  1. Open VLC Media Player on the host computer.
  2. Navigate to Tools > Preferences (or press Ctrl + P).
  3. In the bottom-left corner of the window, switch the Show settings option from Simple to All.
  4. In the left sidebar, click on Interface, then select Main interfaces.
  5. Check the box next to Web to enable the HTTP remote control interface.

Step 2: Set the Web Access Password

VLC requires a password for web access to prevent unauthorized control.

  1. While still in the All settings view, expand Main interfaces in the left sidebar and select Lua.
  2. Under the Lua HTTP section on the right, locate the Password field.
  3. Enter a secure password of your choice. Leave the username field blank, as VLC uses a blank username by default.
  4. Click Save and restart VLC for the changes to take effect.

Step 3: Find the Host IP Address

To control VLC from another device, you need the local IP address of the computer running VLC:

  • Windows: Open the Command Prompt, type ipconfig, and look for your IPv4 Address (typically starting with 192.168.x.x or 10.0.x.x).
  • macOS: Open System Settings > Network, select your active connection, and view the IP address.
  • Linux: Open a terminal and run ip addr or hostname -I.

Step 4: Access the Interface from a Browser

  1. Open any standard web browser on your secondary device (phone, tablet, or another computer connected to the same Wi-Fi or local network).
  2. Enter the host computer's IP address followed by port 8080 into the address bar (for example, http://192.168.1.50:8080). If testing on the host computer itself, use http://localhost:8080.
  3. When prompted for authentication, leave the username blank and enter the password configured in Step 2.

The browser will display the VLC web interface, giving you full control over playback, volume, tracks, and the media library directly from your browser. Ensure that port 8080 is allowed through the host computer's firewall if the connection fails to load.
