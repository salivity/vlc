VLC Mosaic: Stream Multiple Videos Simultaneously

VLC Media Player can generate a visual mosaic displaying multiple simultaneous video streams on a single canvas. By using the built-in VideoLAN Manager (VLM) alongside VLC's mosaic bridge filter, users can composite several local video files, webcams, or network streams (such as RTSP feeds from security cameras) into a customized grid layout. This guide outlines how the VLC mosaic feature works, provides a functional configuration template, and explains how to launch your multi-stream display.

How the VLC Mosaic System Works

VLC constructs a mosaic using three primary elements:

  1. A Background Canvas: A base video or static image stream that defines the overall resolution, aspect ratio, and frame rate of the output window.
  2. Sub-Streams: Individual video sources (files, capture devices, or network URLs) routed into VLC via mosaic bridge sub-filters.
  3. The VideoLAN Manager (VLM): VLC's internal control interface that manages multiple media inputs, synchronizes them, and positions each video within predefined coordinates on the background canvas.

Creating the VLM Configuration File

The most reliable way to configure a mosaic is by writing a VLM script file (mosaic.vlm).

Below is an example configuration that positions two video streams side-by-side onto a 1920x1080 background:

# Define the background canvas
new background broadcast enabled
setup background input "fake://"
setup background option fake-file="background.png"
setup background option fake-width=1920
setup background option fake-height=1080
setup background option fake-fps=25
setup background output #mosaic-bridge{id=1}:bridge-in:display

# Define Stream 1 (Left side)
new stream1 broadcast enabled
setup stream1 input "rtsp://camera1.local/stream"
setup stream1 output #duplicate{dst=mosaic-bridge{id=stream1,width=960,height=540,x=0,y=270},select=video}

# Define Stream 2 (Right side)
new stream2 broadcast enabled
setup stream2 input "rtsp://camera2.local/stream"
setup stream2 output #duplicate{dst=mosaic-bridge{id=stream2,width=960,height=540,x=960,y=270},select=video}

# Control execution
control background play
control stream1 play
control stream2 play

Key Parameters:

  • width and height: The target display size for each individual sub-stream.
  • x and y: The pixel offset from the top-left corner of the background where each sub-stream renders.
  • input: Can be a local file path, direct capture device, or streaming protocol (rtsp://, http://, etc.).

Launching the Mosaic via Command Line

Because mosaic setups require parameters not accessible through the standard graphical user interface, you must execute VLC via the command line or terminal.

Run the following command, replacing the paths with your actual installation and file locations:

Windows:

vlc.exe --vlm-conf mosaic.vlm --mosaic-width=1920 --mosaic-height=1080 --mosaic-keep-aspect-ratio

Linux / macOS:

vlc --vlm-conf mosaic.vlm --mosaic-width 1920 --mosaic-height 1080 --mosaic-keep-aspect-ratio

Performance and Resource Management

  • Hardware Decoding: Decoding multiple high-resolution (1080p or 4K) streams simultaneously places a heavy load on the CPU and GPU. For four or more streams, lower the source resolution or frame rates at the stream source if playback stutters.
  • Network Bandwidth: If displaying remote RTSP or HTTP feeds, ensure your local network interface has sufficient bandwidth to process multiple concurrent streams without packet loss.
  • Audio Handling: By default, mosaic configurations only bridge video (select=video). Audio channels from multiple simultaneous streams can conflict; it is best practice to mute sub-streams or route only one specific stream's audio to the output.
