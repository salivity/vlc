Enable and Configure the VLC HTTP REST API

This guide provides a straightforward walkthrough on how to enable and configure the built-in HTTP REST API in the VLC media player. You will learn how to activate the web interface, set up authentication credentials, configure network access, and execute control commands using standard HTTP requests to automate or remotely control media playback.

Step 1: Enable the Web Interface

By default, the HTTP interface in VLC is turned off. To turn it on:

  1. Open VLC Media Player.
  2. Go to Tools > Preferences (or press Ctrl + P on Windows/Linux, Cmd + , on macOS).
  3. In the bottom-left corner under Show settings, select the All radio button to access advanced preferences.
  4. In the left sidebar, navigate to Interface > Main interfaces.
  5. Check the box labeled Web (http).

Step 2: Set the Lua HTTP Password

VLC requires a password for HTTP access; requests without a password configured will fail.

  1. In the advanced preferences sidebar, expand Main interfaces and click on Lua.
  2. Under the Lua HTTP section on the right, locate the Password field.
  3. Enter a secure password of your choice. (Leave the username blank, as VLC defaults to an empty username).
  4. Click Save.
  5. Restart VLC for the changes to take effect.

Step 3: Verify the Connection

Once VLC is restarted with media loaded:

  1. Open your web browser or an API client like Postman or cURL.
  2. Navigate to http://localhost:8080.
  3. When prompted for authentication, leave the username blank and enter the password set in Step 2.
  4. You should see VLC’s built-in web control dashboard.

Step 4: Interact with the REST API

The VLC HTTP interface exposes endpoints returning XML and JSON data located in the /requests/ path. All requests must include HTTP Basic Authentication (username empty, password as configured).

Key Endpoints:

  • Get Player Status (JSON):
    GET http://localhost:8080/requests/status.json

  • Get Playlist (JSON):
    GET http://localhost:8080/requests/playlist.json

  • Get Current Information:
    GET http://localhost:8080/requests/status.xml

Common Control Commands:

Control commands are sent as query parameters to the status endpoint (/requests/status.json):

  • Play/Pause Toggle:
    http://localhost:8080/requests/status.json?command=pl_pause
  • Stop Playback:
    http://localhost:8080/requests/status.json?command=pl_stop
  • Next Track:
    http://localhost:8080/requests/status.json?command=pl_next
  • Previous Track:
    http://localhost:8080/requests/status.json?command=pl_previous
  • Set Volume (0 to 512, where 256 is 100%):
    http://localhost:8080/requests/status.json?command=volume&val=256
  • Seek to Position (in seconds):
    http://localhost:8080/requests/status.json?command=seek&val=120

Example using cURL:

curl -u ":your_password" "http://localhost:8080/requests/status.json?command=pl_pause"

Step 5: Enable Remote Network Access (Optional)

By default, VLC only permits connections from localhost (127.0.0.1). To allow connections from other machines on your local network:

  1. Navigate to the VLC installation directory:
    • Windows: C:\Program Files\VideoLAN\VLC\lua\http\
    • Linux: /usr/share/vlc/lua/http/
    • macOS: /Applications/VLC.app/Contents/MacOS/share/lua/http/
  2. Open the .hosts file in a text editor with administrative/root privileges.
  3. Uncomment (remove the #) the IP address range corresponding to your local network (e.g., 192.168.0.0/16 or 10.0.0.0/8), or add the specific IP address of the machine making the API calls.
  4. Save the file and restart VLC.
