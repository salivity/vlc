Disable VLC Recent Items in Windows Jump List

This guide explains how to prevent VLC Media Player from recording and displaying your recently played media files in the Windows taskbar Jump List. By adjusting a single privacy setting within VLC or modifying your Windows system settings, you can keep your media playback history private and maintain a clean, clutter-free taskbar.

Method 1: Turn Off Playback History in VLC Settings

The most effective way to stop VLC from populating the Jump List is to disable its internal history tracking.

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P).
  3. Ensure you are on the Interface tab (selected by default on the left or top).
  4. Scroll down to the Privacy / Network Interaction section.
  5. Uncheck the box labeled Save recently played items.
  6. Click Save at the bottom right.
  7. Restart VLC to apply the changes.

Once disabled, VLC will immediately stop adding newly opened media files to the Windows Jump List.

How to Clear Existing Jump List Items

Disabling future tracking does not automatically remove files that are already pinned or listed in your current Jump List. To remove existing items:

  1. Right-click the VLC icon on your Windows taskbar.
  2. In the Jump List menu, hover over an unwanted item.
  3. Click the Unpin icon (if pinned) or right-click the file and select Remove from this list.
  4. Alternatively, open VLC, go to Media > Open Recent Media, and click Clear.

Method 2: Disable Jump Lists Globally in Windows

If you prefer to disable recent file lists across all applications, including VLC, you can do so through Windows Settings.

On Windows 11:

  1. Open Settings (press Windows Key + I).
  2. Navigate to Personalization > Start.
  3. Toggle off Show recently opened items in Start, Jump Lists, and File Explorer.

On Windows 10:

  1. Open Settings (press Windows Key + I).
  2. Navigate to Personalization > Start.
  3. Turn off the toggle for Show recently opened items in Jump Lists on Start or the taskbar and in File Explorer Quick Access.
