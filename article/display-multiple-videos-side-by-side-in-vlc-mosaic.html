Display Multiple Videos Side-by-Side in VLC Mosaic

VLC Media Player can process and display multiple video streams simultaneously side-by-side using its built-in mosaic framework. This feature relies on the VideoLAN Manager (VLM) engine and transcode filters to aggregate several video inputs into a single grid-based canvas. This guide explains how the VLC mosaic framework operates, details the required configuration files, and outlines the commands necessary to run a multi-video display.

How the VLC Mosaic Framework Works

The mosaic framework functions by layering multiple video feeds onto an underlying background canvas. One video channel acts as the master canvas, defining the output resolution, aspect ratio, and frame rate. Secondary streams are piped through the mosaic-bridge sub-filter, scaled down according to user parameters, and placed into designated positions (such as a 2x2 grid or a dual-stream side-by-side layout).

Because the standard VLC graphical user interface lacks direct controls for complex mosaic operations, configuring the layout requires a VLM configuration file executed via the command line interface (CLI).

Setting Up a Mosaic Configuration File

To render streams side-by-side, you must create a plain text file (e.g., mosaic.vlm) containing the stream definitions and rendering instructions.

A basic setup for two side-by-side 720p streams onto a 1080p canvas looks like this:

# Define background canvas
new background broadcast enabled
setup background input "fake://"
setup background option fake-width=1920
setup background option fake-height=1080
setup background option fake-fps=30
setup background output #transcode{sfilter=mosaic{width=1920,height=1080,cols=2,rows=1,order="stream1,stream2",keep-aspect-ratio=1},vcodec=mp4v}:display

# Define Channel 1
new stream1 broadcast enabled
setup stream1 input "rtsp://example.com/camera1"
setup stream1 output #duplicate{dst=mosaic-bridge{id=stream1,width=960,height=540},select=video}

# Define Channel 2
new stream2 broadcast enabled
setup stream2 input "rtsp://example.com/camera2"
setup stream2 output #duplicate{dst=mosaic-bridge{id=stream2,width=960,height=540},select=video}

# Launch streams
control background play
control stream1 play
control stream2 play

Essential Parameters Explained

  • cols and rows: Specifies the grid geometry. For a simple side-by-side display, set cols=2 and rows=1. For a four-camera display, set cols=2 and rows=2.
  • order: Defines the sequence in which each stream identifier fills the defined grid slots from left to right, top to bottom.
  • mosaic-bridge: Directs VLC to scale the individual feed to the allocated grid slot dimensions before rendering it on the main canvas.
  • keep-aspect-ratio: Ensures the incoming video is letterboxed or pillarboxed rather than stretched out of proportion.

Executing the Mosaic via Command Line

Once your .vlm configuration file is saved, open your terminal or command prompt and execute VLC with the --vlm-conf parameter:

vlc --vlm-conf mosaic.vlm --mosaic-width 1920 --mosaic-height 1080

On Windows, use the full path to the executable:

"C:\Program Files\VideoLAN\VLC\vlc.exe" --vlm-conf mosaic.vlm

Hardware and Performance Considerations

Processing multiple incoming streams requires decoding each individual input simultaneously alongside an active transcoding step to compile the mosaic canvas. Ensure your hardware has sufficient CPU or GPU headroom, especially when rendering multiple high-bitrate or 4K streams. If stuttering occurs, downscale the input streams directly in the mosaic-bridge configuration to lower resource consumption.
