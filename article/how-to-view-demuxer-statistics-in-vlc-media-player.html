How to View Demuxer Statistics in VLC Media Player

This guide provides a straightforward walkthrough on how to locate and read demuxer statistics using VLC Media Player's built-in Media Information tool. By accessing these statistics, you can monitor the real-time processing of your media files, including demuxed data rates, read buffers, and stream health, which is essential for diagnosing playback issues and analyzing media container efficiency.

Steps to Access Demuxer Statistics

  1. Open and Play the Media File Launch VLC Media Player and open the video or audio file, network stream, or disc you wish to inspect. The media must be actively playing or paused to generate real-time demuxer data.

  2. Open the Media Information Window

    • Windows / Linux: Click on Tools in the top menu bar and select Media Information, or press the keyboard shortcut Ctrl + I.
    • macOS: Click on Window in the top menu bar and select Media Information, or press Cmd + I.

  3. Navigate to the Statistics Tab In the Current Media Information window that appears, click on the Statistics tab located at the top right.

  4. Expand the Input/Read Section Demuxing metrics are grouped under the first collapsible section labeled Input/Read. Click the small arrow or plus icon next to Input/Read if it is not already expanded.

Understanding Demuxer Metrics

Within the Input/Read block, look for the following specific demuxer values:

  • Demuxed data: Displays the cumulative amount of raw audio, video, and subtitle data extracted from the container format since playback began.
  • Content bitrate / Demux bitrate: Shows the real-time processing speed at which the demuxer is splitting elementary streams out of the container file.
  • Read bytes: The total raw bytes fetched from your storage drive or network buffer before demuxing occurs.
  • Input bitrate: The current rate at which data is arriving at the demuxer from the source.

These counters update dynamically while playback continues, allowing you to observe bitrate spikes, buffering stalls, or stream inconsistencies in real time.
