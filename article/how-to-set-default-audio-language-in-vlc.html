How to Set Default Audio Language in VLC

If you regularly watch multilingual movies, anime, or TV shows, manually changing the audio track every time a new video starts can be tedious. This guide explains how to configure VLC Media Player’s internal preferences to permanently set a default audio language. By entering the correct language codes into VLC's settings, the player will automatically detect and play your preferred audio stream whenever multiple tracks are available.

Step-by-Step Guide to Setting a Default Audio Track

  1. Open VLC Preferences

    • Launch VLC Media Player.
    • In the top menu bar, click on Tools and select Preferences. (Alternatively, press Ctrl + P on Windows/Linux or Cmd + , on macOS).

  2. Navigate to the Audio Settings

    • In the Preferences window, select the Audio tab from the top navigation bar.
    • Make sure the Simple settings view is selected in the bottom-left corner under Show settings.

  3. Set the Preferred Audio Language

    • Scroll down to the bottom section labeled Tracks.
    • Locate the text input field labeled Preferred audio language.
    • Type the language code for your desired language. VLC accepts standard two-letter (ISO 639-1) or three-letter (ISO 639-2) codes, as well as full names.

  4. Save and Apply

    • Click the Save button in the bottom-right corner.
    • Restart VLC to ensure the changes take effect.

Understanding Language Codes

Video files use standardized international codes to tag audio tracks. For the best compatibility, you can enter multiple comma-separated values so VLC catches the track regardless of how the file was encoded.

Common language code examples:

  • English: eng, en, English
  • Spanish: spa, es, Spanish
  • Japanese: jpn, ja, Japanese
  • French: fra, fre, fr, French
  • German: deu, ger, de, German

If a file contains multiple languages, VLC will scan the tracks from left to right based on your entered list and select the first match it finds. If none of the specified languages are present, VLC will default to the file's primary audio track.
