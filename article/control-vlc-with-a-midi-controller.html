Control VLC with a MIDI Controller

While VLC Media Player does not feature native support for MIDI input, you can reliably trigger its media functions using any MIDI controller by using intermediate translation software. Because VLC readily accepts standard keyboard shortcuts and remote network commands, you can convert incoming MIDI signals—such as Control Change (CC) or Note On messages—into keystrokes or API calls that control playback, volume, track selection, and more.

The Standard Approach: MIDI-to-Keystroke Mapping

The most straightforward way to link a MIDI controller to VLC is through software that converts MIDI data into virtual keyboard presses.

  1. Choose a Translation Tool:

    • Windows: Tools like Bome MIDI Translator Classic, MIDI2Key, or FreePIE.
    • macOS: Applications like OSCulator, Keyboard Maestro, or MidiStroke.
    • Linux: Utilities like mididings or xdotool.

  2. Map the Controls: Connect your MIDI controller and launch your translator tool. Assign specific hardware inputs to VLC’s default hotkeys:

    • Play / Pause: Map a pad or button to the Spacebar.
    • Stop: Map a button to S.
    • Volume Up / Down: Map an endless encoder or continuous fader to Ctrl + Up Arrow and Ctrl + Down Arrow (or Cmd on macOS).
    • Next / Previous Track: Map buttons to N and P.
    • Fullscreen Toggle: Map a button to F.

Enabling VLC Global Hotkeys

By default, VLC only listens for keystrokes when its window is active and focused. If you want your MIDI controller to work while other applications are in use, you must configure global hotkeys inside VLC:

  1. Open VLC and navigate to Tools > Preferences (or VLC > Settings on macOS).
  2. Click the Hotkeys tab.
  3. Locate the action you want to assign.
  4. Double-click the Global column for that action and assign the corresponding key combination that your MIDI translator generates.
  5. Click Save and restart VLC for the changes to take effect.

Advanced Approach: Controlling VLC via HTTP or Telnet

For users who want precise analog feedback—such as using motorized faders or knobs that send absolute values rather than incremental keystrokes—you can use custom scripts (written in Python, Node.js, or AutoHotkey) to bridge the controller to VLC's network interfaces.

  1. Enable the Web or Telnet interface in VLC under Preferences > All > Interface > Main interfaces.
  2. Write or run a script using a MIDI library (such as mido in Python) to read incoming MIDI CC values (ranging from 0 to 127).
  3. Translate those values into VLC API requests (for example, mapping 0–127 to VLC's 0–512 volume scale) and send them via HTTP commands to http://localhost:8080/requests/status.xml.

This method runs silently in the background, does not interfere with the system clipboard or keyboard focus, and offers absolute positioning control over playback scrub bars and volume faders.
