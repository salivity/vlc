Does VLC Support WASAPI Audio Output?

VLC media player fully supports audio output via the Windows Audio Session API (WASAPI). Introduced natively in VLC version 2.1 and refined in subsequent releases, this feature allows Windows users to route audio directly through Microsoft's modern audio architecture. This guide explains how WASAPI works in VLC, the difference between shared and exclusive modes, and how to configure your settings for optimal sound quality.

Understanding WASAPI in VLC

WASAPI is Microsoft’s low-latency audio interface designed for Windows Vista and newer operating systems. When using WASAPI, VLC communicates directly with the Windows audio engine or the audio hardware itself.

VLC supports two primary operating modes for WASAPI:

  • Shared Mode: The default behavior. Audio from VLC is sent to the Windows audio engine, mixed with sounds from other applications, and resampled to the default format defined in Windows Sound Settings.
  • Exclusive Mode: VLC takes direct, exclusive control of the audio endpoint. This bypasses the Windows software mixer, prevents system alert sounds from interrupting playback, and allows for bit-perfect audio delivery to an external DAC or receiver.

How to Enable WASAPI in VLC

To route VLC’s audio output through WASAPI, follow these steps:

  1. Open VLC media player.
  2. Navigate to the top menu and select Tools > Preferences (or press Ctrl + P).
  3. Click on the Audio tab at the top.
  4. Locate the Output section.
  5. In the Output module drop-down menu, change the setting from Automatic to Windows Audio Session API output.
  6. In the Device drop-down menu, select the specific audio endpoint (such as your DAC, speakers, or headphones) rather than the "Default" option to ensure the correct hardware interface is engaged.
  7. Click Save at the bottom right.
  8. Restart VLC media player to apply the changes.

Enabling Exclusive Mode for Bit-Perfect Audio

If you require bit-perfect playback (ideal for high-resolution FLAC files, DSD, or multichannel formats like Dolby TrueHD and DTS-HD Master Audio):

  1. Go to Tools > Preferences.
  2. At the bottom left under Show settings, select All to access advanced configuration options.
  3. In the left-hand sidebar, expand Audio and click on Output modules.
  4. Select WASAPI.
  5. Check the box labeled Use exclusive mode.
  6. If you are bitstreaming encoded audio formats to an external AV receiver, ensure HDMI/SPDIF audio passthrough is enabled under the standard Audio preferences.
  7. Click Save and restart VLC.

Important Considerations

While WASAPI Exclusive Mode offers the highest possible audio fidelity, it will mute all other system sounds, browser audio, and notifications while media is playing in VLC. If you encounter playback errors or silence, confirm that your target audio device supports the sample rate and bit depth of the media file being played.
