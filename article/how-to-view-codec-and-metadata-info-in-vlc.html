How to View Codec and Metadata Info in VLC

VLC Media Player includes built-in tools that allow you to inspect the technical specifications and embedded metadata of any audio or video file. This guide provides a straightforward walkthrough on how to access the Media Information panel in VLC to view codecs, bitrates, resolutions, audio tracks, and tagging information.

Accessing Media Information

To view the details of a media file, open the file in VLC and follow these steps:

  1. Click on the Tools menu in the top navigation bar.
  2. Select Media Information from the drop-down menu.
    • Windows/Linux Shortcut: Press Ctrl + I
    • macOS Shortcut: Press Cmd + I

A window titled Current Media Information will appear with several tabs containing different levels of file data.

Reading Metadata (General Tab)

The General tab displays the file's standard metadata tags. If the file contains embedded information, you will see fields such as:

  • Title
  • Artist / Performer
  • Album
  • Genre
  • Date / Year
  • Copyright details and custom comments

You can edit these fields directly within VLC and click Save Metadata at the bottom of the window to apply changes to the file.

Checking Codec and Technical Details (Codec Tab)

The Codec tab breaks down the file's individual streams, typically dividing them into video, audio, and subtitle tracks.

  • Video Streams: Displays the codec format (e.g., H.264, HEVC, VP9), video resolution (width and height), frame rate (fps), decoded format, and color space.
  • Audio Streams: Displays the audio codec (e.g., AAC, MP3, FLAC), sample rate (e.g., 44100 Hz or 48000 Hz), number of channels (e.g., Stereo or 5.1), and bits per sample.
  • Subtitle Streams: Displays the format and language of any internal text or bitmap subtitle tracks.

Viewing Playback Performance (Statistics Tab)

The Statistics tab provides real-time data regarding how the file is being processed during playback. This section includes:

  • Audio/Video Bitrate: Current input and streaming bitrates.
  • Video Frames: The total number of decoded frames versus dropped or lost frames, which helps diagnose playback stuttering or hardware decoding issues.
  • Audio Buffers: The number of played and lost audio buffers.
