Disable Automatic Metadata Retrieval in VLC

VLC Media Player automatically queries third-party online databases to fetch album artwork, track details, and other media information whenever you open a file. While convenient for cataloging, this background activity sends file-related data over the network and consumes bandwidth. This guide provides clear, step-by-step instructions to disable automatic internet metadata retrieval in VLC across Windows, macOS, and Linux to ensure your media playback remains entirely offline and private.

Disabling Network Metadata in Simple Preferences

The fastest way to stop VLC from connecting to the internet for media information is through the basic interface settings.

  1. Open VLC Media Player.
  2. Open the Preferences menu:
    • Windows / Linux: Click Tools in the top menu bar and select Preferences, or press Ctrl + P.
    • macOS: Click VLC in the menu bar and select Settings... (or Preferences...), or press Cmd + ,.
  3. Ensure the Interface tab is selected on the left or top panel.
  4. Scroll down to the Privacy / Network Interaction section.
  5. Uncheck the box labeled Allow metadata network access.
  6. Locate the Album art download policy dropdown menu and change it from As soon as track is added to Manual download only.
  7. Click Save at the bottom of the window.

Disabling Track and Art Fetching in Advanced Settings

To guarantee that VLC does not trigger secondary background scripts or extensions to query external servers, turn off additional fetch settings in the advanced menu.

  1. Reopen the Preferences window (Ctrl + P on Windows/Linux, Cmd + , on macOS).
  2. At the bottom-left corner under Show settings, switch the selection from Simple to All.
  3. In the left-hand navigation tree, expand the Interface category.
  4. Click on Main interfaces, then select Qt (on Windows and Linux systems).
  5. Scroll down through the options on the right pane until you find the Privacy section.
  6. Uncheck Ask for network policy if it's not defined and ensure any network access options are unchecked.
  7. Return to the left menu, expand Input / Codecs, and click on Demuxers.
  8. Verify that automatic streaming or title retrieval modules are not set to query external servers.
  9. Click Save to apply all modifications.

Restarting VLC

Close VLC Media Player completely and reopen it. Once restarted, VLC will strictly read existing, locally embedded metadata (such as ID3 tags already saved within MP3 or MKV files) and will block all outbound connections to online metadata databases.
