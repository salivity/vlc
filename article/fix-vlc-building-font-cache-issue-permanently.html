Fix VLC Building Font Cache Issue Permanently

The "Building font cache" dialog in VLC Media Player appears when the application scans your system's font directory to prepare rendering engines for video subtitles. When this cache becomes corrupted or contains too many complex fonts, VLC can freeze or delay playback every time a video is opened. This guide provides permanent solutions to eliminate the font cache delay by disabling the font scanning module or clearing corrupted cache files.

Method 1: Change the Text Rendering Module (Recommended)

The most reliable way to prevent VLC from rebuilding the font cache is to switch the subtitle renderer to a dummy module. This disables font scanning entirely.

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P).
  3. In the bottom-left corner under Show settings, select the All radio button to access advanced settings.
  4. In the left sidebar, expand the Video category, expand Subtitles / OSD, and select Text renderer.
  5. Locate the Text rendering module dropdown menu on the right panel.
  6. Change the setting from Default to Dummy font renderer function.
  7. Click Save and restart VLC.

Note: This method disables advanced subtitle font styling, but standard subtitles will still display properly without triggering the cache delay.

Method 2: Delete Corrupted Fontconfig Cache Files

If you want to keep full subtitle font rendering capabilities, the issue is typically caused by a corrupted cache file that VLC fails to read, forcing it to rebuild on every launch. Deleting the existing cache allows VLC to generate a fresh, working version.

On Windows:

  1. Close VLC completely.
  2. Press Windows Key + R to open the Run dialog.
  3. Type %appdata% and press Enter.
  4. Locate and open the vlc folder.
  5. Delete any files or folders named fontconfig or ending in .cache.
  6. Press Windows Key + R again, type %localappdata%, and press Enter.
  7. Look for a fontconfig folder and delete the files inside its cache directory.
  8. Reopen VLC and open a video. Allow the font cache to build one final time; it should not prompt you again.

On Linux:

  1. Close VLC.
  2. Open a terminal and run the following command to remove the user font cache: 
    rm -rf ~/.cache/fontconfig
  3. Regenerate the system font cache cleanly by running: 
    fc-cache -r

Method 3: Reset All VLC Preferences

If previous configuration changes failed to resolve the issue, resetting the entire preference profile will restore factory defaults and purge stuck configuration loops.

  1. In VLC, navigate to Tools > Preferences.
  2. At the bottom of the window, click Reset Preferences.
  3. Confirm the action when prompted.
  4. Restart VLC.
