Force VLC to Open in a Single Instance

By default, opening a new video or audio file often launches a completely new VLC Media Player window, resulting in cluttered screens and multiple media playing simultaneously. You can easily resolve this by configuring VLC's internal preferences to reuse the existing player window. This guide walks you through the exact settings required to force VLC to open all new media files in a single instance on both Windows and macOS, including how to queue files instead of interrupting current playback.

How to Enable Single Instance Mode on Windows

Follow these steps to restrict VLC to one window on Windows:

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar, then select Preferences (or press Ctrl + P).
  3. Ensure the Interface tab is selected on the left or top panel.
  4. Under the Show settings section at the bottom-left corner, ensure Simple is selected.
  5. Scroll down to the Playlist and Instances section.
  6. Check the box labeled Use only one instance when started from file manager.
  7. (Optional) Check the box labeled Enqueue items into playlist in one instance mode. This setting adds new files to your playlist rather than immediately interrupting and replacing the currently playing file.
  8. Click Save at the bottom right.
  9. Close and restart VLC Media Player for the changes to apply.

How to Enable Single Instance Mode on macOS

On macOS, VLC generally restricts playback to a single app instance by default, but it may open individual videos in detached windows depending on your settings. To keep everything inside a single unified window:

  1. Open VLC and press Cmd + , (Comma) to open Preferences.
  2. Select the Interface tab.
  3. Check the box for Use the native fullscreen-mode if you prefer native windowing.
  4. Make sure the option to show controls in full screen or integrate video in interface is checked.
  5. Click Save and restart VLC.
