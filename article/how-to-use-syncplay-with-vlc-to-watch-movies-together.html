How to Use Syncplay with VLC to Watch Movies Together

You can synchronize VLC Media Player across multiple computers using Syncplay, allowing you and your friends to watch videos simultaneously over the internet. This guide provides a straightforward overview of how the tools work together, the prerequisites needed, and a step-by-step walkthrough to configure VLC with Syncplay for a synchronized watch party.

Prerequisites

To get started, everyone participating in the viewing session needs the following:

  1. VLC Media Player: Installed on each participant's computer.
  2. Syncplay: Installed on each participant's computer.
  3. The Same Video File: Syncplay synchronizes playback commands (play, pause, seek), not the actual video stream. Every user must have an identical copy of the movie or video file saved locally.

Step 1: Open Syncplay

Launch Syncplay on your computer. When opened, you will be greeted by the initial configuration window.

Step 2: Set the Media Player Path to VLC

  1. In the Syncplay configuration window, locate the Media Player section.
  2. Select VLC from the dropdown menu (or click Browse to point to vlc.exe on Windows or VLC.app on macOS).
  3. Check the box to remember this path for future sessions.

Step 3: Configure Server and Room Settings

  1. Server Address: Choose a public Syncplay server from the default list (e.g., syncplay.pl:8997), or enter the address of a private server if you host your own.
  2. Username: Enter a nickname so other participants can identify you.
  3. Default Room: Enter a unique room name. All friends who want to watch together must enter this exact room name.

Step 4: Join the Room and Launch VLC

Click the Store configuration and run Syncplay button. Syncplay will automatically launch an instance of VLC integrated with the Syncplay client interface.

Step 5: Load the Video File

  1. Drag and drop your video file into the Syncplay window or the VLC window.
  2. Have your friends perform the same action with their local copies of the file.
  3. Syncplay will display a notification indicating whether all participants' files match in name, size, and duration.

How Controls Work During Playback

Once everyone is in the room and ready:

  • Play/Pause: Pressing play or pause in VLC synchronizes the state across all connected users instantly.
  • Seeking: Jumping forward or backward in the timeline moves everyone to the exact same timestamp.
  • Automatic Sync: If one user's connection lags, Syncplay will automatically pause or slow down the playback slightly until everyone is back in sync.
