How to Combine Audio and Video Files in VLC

VLC Media Player includes built-in functionality to combine (mux) a separate audio track and video file into a single new container format, such as MP4 or MKV. This guide provides a straightforward, step-by-step walkthrough explaining how to use VLC’s advanced open and conversion features to synchronize your media tracks and export them as one unified file without needing dedicated video editing software.

Step-by-Step Guide to Muxing Audio and Video in VLC

  1. Open the Convert/Save Menu
    Launch VLC Media Player. Click on Media in the top menu bar and select Convert / Save... (or press Ctrl + R on Windows, Cmd + Shift + S on macOS).

  2. Select the Primary Video File
    In the File tab, click the Add... button under the File Selection section. Browse your computer, select the video file you want to use, and click Open.

  3. Enable Secondary Audio Track
    At the bottom of the Open Media window, check the box labeled Show more options. Additional settings will appear. Check the box labeled Play another media synchronously (extra audio file, ...).

  4. Add the Audio File
    Click the Browse... button next to the Extra media field. In the new window that appears, click Add..., select your replacement or supplementary audio file, and click Select.

  5. Proceed to Conversion
    Click the Convert / Save button at the bottom of the Open Media dialog.

  6. Choose the Output Format (Container)
    In the Convert dialog box, locate the Profile dropdown menu. Choose your desired output format (for example, Video - H.264 + MP3 (MP4)).
    Optional: Click the wrench icon next to the dropdown to modify encapsulation (MP4, MKV, WebM) or configure whether the video and audio streams should be re-encoded or kept as original streams.

  7. Set Destination and Start
    Click Browse next to the Destination file field, select where you want to save the new file, name it, and ensure the proper file extension is included (e.g., .mp4). Click Save, then click Start.

VLC will process the files and save the newly muxed media to your specified location. The progress bar at the bottom of VLC acts as the encoding timer; once it reaches the end, your new file is ready to play.
