VLC UDP Multicast Streaming on Local Network

Yes, VLC Media Player can fully function as a UDP multicast streaming server across a local area network (LAN). This article explains how to configure VLC to broadcast video or audio to multiple local devices simultaneously using a single network stream, how client devices can receive that broadcast, and the essential network prerequisites required for multicast traffic to flow properly.

How UDP Multicast Works in VLC

Unlike unicast streaming—which establishes a distinct data connection for every connected client—multicast sends a single data stream from the host to a designated multicast IP address (within the range 224.0.0.0 to 239.255.255.255). Network switches handle the duplication of the packets, forwarding the stream only to devices that actively request it. This drastically reduces the bandwidth footprint on the host machine and the local network when broadcasting to multiple endpoints.

Step-by-Step Server Setup

To configure VLC as the multicast streaming server:

  1. Open VLC Media Player.
  2. Click on Media in the top menu and select Stream... (or press Ctrl + S).
  3. Under the File tab, click Add... to choose the media file you want to stream. You can also select capture devices or discs.
  4. Click the Stream button at the bottom.
  5. In the Stream Output setup window, click Next.
  6. Under Destinations, change the drop-down menu to UDP (legacy) and click Add.
  7. Enter a valid multicast IP address in the Address field (for local private networks, using the administratively scoped range 239.255.0.0/16 is standard, such as 239.255.1.1).
  8. Leave the default port set to 1234 (or specify your preferred port) and click Next.
  9. Select a transcoding profile (such as Video - H.264 + MP3 (TS)) or leave it uncompressed if your clients support the source codec natively. Container formats like MPEG-TS work best for UDP streaming.
  10. Click Stream to begin broadcasting.

Step-by-Step Client Setup

To view the multicast stream on any computer connected to the same local subnet:

  1. Open VLC Media Player on the client device.
  2. Click Media and select Open Network Stream... (or press Ctrl + N).
  3. In the URL field, enter the multicast address and port formatted as follows: 
    udp://@239.255.1.1:1234
    (Note: The @ symbol instructs VLC to listen on that specific multicast group and port).
  4. Click Play. The stream will begin playing as soon as network packets are received.

Network Requirements and Troubleshooting

For UDP multicast streaming to work without interruption, ensure your local environment meets the following conditions:

  • Firewall Rules: The host machine's firewall must allow outbound UDP traffic on the selected port, and client firewalls must permit inbound UDP packets on that same port.
  • IGMP Snooping: Managed network switches should have Internet Group Management Protocol (IGMP) snooping enabled so that multicast packets are only forwarded to ports that have subscribed to the stream.
  • TTL (Time to Live): If the stream needs to cross routers or layer-3 switches, adjust the Time-To-Live (TTL) value in VLC's advanced streaming options. By default, the TTL is often set to 1, which restricts the stream to the immediate local subnet.
