Set Up VLC as a Looping Digital Signage Player

Using VLC Media Player as a digital signage solution provides a cost-effective, reliable way to display promotional videos, menus, and announcements on an endless loop. By disabling on-screen interface elements, suppressing pop-up track titles, enabling continuous playlist playback, and configuring full-screen mode, you can turn any computer connected to a monitor into an automated digital signage kiosk.

Step 1: Enable Endless Looping

To ensure your media continuously replays without manual intervention:

  1. Open VLC Media Player.
  2. Load your videos or images into a playlist by selecting View > Playlist and dragging your media files into the window.
  3. Locate the loop button at the bottom playback control bar (two arrows in a loop).
  4. Click the button twice to select Loop All (the icon will highlight with a small "all" or double arrow indicator, depending on your version).

Step 2: Configure Automatic Fullscreen Playback

Set VLC to always open videos in full-screen mode:

  1. Navigate to Tools > Preferences (or press Ctrl + P).
  2. Select the Video tab.
  3. Under the "Display" section, check the box for Fullscreen.
  4. Click Save at the bottom.

Step 3: Disable Media Titles and On-Screen Display (OSD)

By default, VLC displays the file name at the start of every video. To maintain a professional display:

  1. Go to Tools > Preferences.
  2. Click the Subtitles / OSD tab.
  3. Under the "On Screen Display" section, uncheck Show media title on start.
  4. Click Save.

Step 4: Hide Controls and System Notifications

To prevent playback controls and notifications from interrupting the display:

  1. Go to Tools > Preferences.
  2. At the bottom left under "Show settings", select All to view advanced preferences.
  3. Navigate to Interface > Main interfaces > Qt.
  4. Uncheck Show notification popup on track change.
  5. Click Save.

Step 5: Automate with a Startup Shortcut or Command Line

The most dependable way to deploy VLC as signage is by launching it via a command line script. This ensures the correct settings apply even if the computer restarts.

Create a desktop shortcut or a .bat file (Windows) with the following command target:

vlc --fullscreen --loop --no-video-title-show "C:\Path\To\Your\Playlist.xspf"

For a completely borderless and non-interactive presentation, you can also add:

  • --play-and-exit (if running an external scheduler)
  • --no-audio (if your signage only requires video)
  • --mouse-hide-timeout=0 (to hide the mouse cursor instantly)

To automate playback upon system reboot, place your shortcut or script into the operating system's Startup folder.
