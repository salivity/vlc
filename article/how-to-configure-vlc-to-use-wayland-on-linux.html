How to Configure VLC to Use Wayland on Linux

This guide explains how to configure the VLC media player to run natively on the Wayland display server in Linux instead of relying on XWayland. By default, VLC 3.0 relies on the X11 compatibility layer on many distributions, which can cause scaling artifacts, higher resource usage, and screen tearing. By installing the necessary display plugins, adjusting internal video output settings, and passing the proper Qt environment variables, you can enable smooth, native Wayland rendering on desktop environments such as GNOME and KDE Plasma.

Step 1: Install the VLC Wayland Video Output Plugin

Most Linux distributions separate the native Wayland output module from the core VLC package. You must install this plugin first to enable Wayland rendering.

  • Debian / Ubuntu / Linux Mint: 
    sudo apt update
sudo apt install vlc-plugin-wayland
  • Fedora: 
    sudo dnf install vlc-plugin-wayland
  • Arch Linux / Manjaro: The default vlc package in Arch Linux includes Wayland support by default.

Step 2: Configure the Video Output in VLC Preferences

Once the plugin is installed, configure VLC to use Wayland for rendering video surfaces.

  1. Open VLC Media Player.
  2. Click Tools in the top menu and select Preferences (or press Ctrl + P).
  3. In the bottom-left corner of the window, switch Show settings from Simple to All.
  4. In the left sidebar, navigate to Video > Output modules.
  5. Click on Output modules to view the drop-down menu on the right. Change Video output module from Automatic to Wayland shared memory video output or Wayland video output.
  6. Click Save and restart VLC.

Step 3: Run the User Interface Natively on Wayland

Because VLC uses the Qt graphical toolkit, the application window and controls default to X11 unless instructed otherwise. You can force the interface to run natively on Wayland using the QT_QPA_PLATFORM environment variable.

To test native execution from the terminal:

QT_QPA_PLATFORM=wayland vlc

If you encounter window decoration or crashing issues on older Qt5 builds, you can allow a fallback to X11:

QT_QPA_PLATFORM="wayland;xcb" vlc

Step 4: Make Native Wayland Execution Permanent

To ensure VLC always opens natively on Wayland without using the terminal, update its application launcher.

  1. Copy the system desktop file to your local directory: 
    cp /usr/share/applications/vlc.desktop ~/.local/share/applications/
  2. Open the file in a text editor: 
    nano ~/.local/share/applications/vlc.desktop
  3. Locate the line that begins with Exec= and modify it to include the environment variable: 
    Exec=env QT_QPA_PLATFORM=wayland /usr/bin/vlc --started-from-file %U
  4. Save the file and exit. Your desktop environment will now launch VLC natively on Wayland.

Step 5: Verify Native Wayland Execution

To verify that VLC is running natively and not through the XWayland translation layer, start playback and run the following command in a terminal:

xlsclients

If VLC is running natively under Wayland, it will not appear in the list generated by xlsclients. If it appears in the output, it is still utilizing XWayland.
