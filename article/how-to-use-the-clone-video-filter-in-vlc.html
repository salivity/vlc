How to Use the Clone Video Filter in VLC

VLC Media Player includes a built-in clone filter that duplicates a playing video across multiple separate windows in real time. This guide explains how to enable the clone video filter, configure the number of duplicate screens, and disable the effect when you are finished.

Step 1: Open Effects and Filters

  1. Launch VLC Media Player and start playing your video.
  2. Click on the Tools menu at the top of the interface.
  3. Select Effects and Filters from the dropdown menu, or press Ctrl + E (Cmd + E on macOS).

Step 2: Enable the Clone Filter

  1. In the Adjustments and Effects window, click on the Video Effects tab.
  2. Navigate to the Advanced tab (labeled as Vout/Overlay in some VLC releases).
  3. Look for the Clone option and check the box next to it.

Step 3: Set the Number of Windows

  1. Next to the Clone checkbox, use the counter arrows or type directly into the field to specify how many identical windows you want to display.
  2. Click Close at the bottom of the window to apply the settings.

VLC will immediately spawn the specified number of duplicate playback windows alongside the original. Each window operates simultaneously, displaying the exact same frame-synchronized video feed. You can drag these individual windows across different monitors or arrange them side by side on a single display.

How to Disable the Clone Filter

To return to standard single-window playback:

  1. Press Ctrl + E to open the Adjustments and Effects window.
  2. Go to Video Effects > Advanced.
  3. Uncheck the Clone box.
  4. Click Close.

The duplicated windows will close immediately, leaving only the primary VLC playback window active.
