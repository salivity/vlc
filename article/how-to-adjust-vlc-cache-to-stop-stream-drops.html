How to Adjust VLC Cache to Stop Stream Drops

Streaming high-latency video feeds over protocols like RTSP, HTTP, or RTMP often results in stuttering, dropped frames, or sudden disconnects when network packets arrive out of order. VLC Media Player mitigates this issue by pre-loading data into a buffer before playback begins. Increasing this buffer gives VLC more time to absorb latency spikes and process late packets, ensuring smooth and continuous playback.

Method 1: Adjust Global Network Caching

This method changes the default caching duration for all network streams opened in VLC.

  1. Open VLC Media Player.
  2. Click on Tools in the top menu bar and select Preferences (or press Ctrl + P).
  3. At the bottom-left corner of the window, locate Show settings and select the All radio button to switch to advanced preferences.
  4. In the left sidebar, click on Input / Codecs.
  5. Scroll down to the bottom of the right pane until you reach the Advanced section.
  6. Locate the Network caching (ms) field. The default value is typically 1000 (1 second).
  7. Increase this value depending on your network conditions:
    • Moderate latency: Set to 3000 (3 seconds).
    • High latency / unstable connection: Set to 5000 to 10000 (5 to 10 seconds).
  8. Click Save and restart VLC for the changes to take effect.

Method 2: Adjust Caching for an Individual Stream

If you only want to apply a larger buffer to a specific URL without altering your global settings:

  1. Click on Media in the top menu and select Open Network Stream... (or press Ctrl + N).
  2. Paste the network URL into the text field.
  3. Check the box labeled Show more options at the bottom-left of the dialog box.
  4. Locate the Caching box.
  5. Enter your desired buffer size in milliseconds (e.g., 5000 ms for a 5-second buffer).
  6. Click Play to start the stream.

Recommended Caching Profiles

  • Local Network (LAN/Low Latency): 500 ms to 1000 ms (Prioritizes low delay).
  • Standard Internet Streams: 2000 ms to 3000 ms (Good balance between latency and stability).
  • Unstable/Satellite/High-Jitter Links: 5000 ms to 15000 ms (Prioritizes stability over real-time delivery).

Note: Higher cache values will introduce a noticeable delay before playback begins and will cause live streams to lag further behind real-time, but it provides the highest resistance against stream drops.
