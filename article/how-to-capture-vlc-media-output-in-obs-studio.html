How to Capture VLC Media Output in OBS Studio

Capturing VLC media output in OBS Studio allows you to seamlessly integrate video playlists, audio tracks, and live network streams directly into your broadcasts or recordings. This guide outlines the most effective methods to achieve this, focusing on the native VLC Video Source integration built into OBS Studio as well as the standard Window Capture fallback method.

Method 1: Using the Native VLC Video Source (Recommended)

OBS Studio includes a dedicated "VLC Video Source" that runs VLC's playback engine directly inside OBS, eliminating the need to have the VLC application open on your desktop.

Prerequisites

  • Both OBS Studio and VLC Media Player must share the same bit architecture (e.g., 64-bit OBS requires 64-bit VLC). If VLC is 32-bit, the option will not appear in OBS.

Steps

  1. Open OBS Studio.
  2. In the Sources dock, click the + (Add) button.
  3. Select VLC Video Source from the menu.
  4. Name the source and click OK.
  5. In the properties window, configure your playback behavior:
    • Visibility behavior: Choose whether media pauses or stops when hidden.
    • Network caching: Adjust buffer settings if streaming from a URL.
  6. Under the Playlist section, click the + icon on the right to add media:
    • Select Add Files for local video and audio files.
    • Select Add Directory to load an entire folder.
    • Select Add URL to stream via RTSP, RTMP, or HTTP.
  7. Click OK to apply the settings.

Method 2: Using Window Capture

If you prefer to control playback manually via the external VLC media player interface, use OBS Studio's Window Capture source.

Steps

  1. Open VLC Media Player on your computer and begin playing your video.
  2. Switch to OBS Studio.
  3. In the Sources dock, click the + button and select Window Capture.
  4. Name the source and click OK.
  5. In the Window drop-down menu, select [vlc.exe]: VLC media player.
  6. Set Capture Method to Automatic or Windows 10 (1903 and up).
  7. Ensure Capture Cursor is unchecked if you do not want your mouse visible on the stream.
  8. Click OK.

Troubleshooting Common Issues

  • Missing "VLC Video Source" in OBS: Ensure both OBS and VLC are the 64-bit versions. Reinstall VLC using the 64-bit installer if the source does not show up.
  • Black Screen with Window Capture: In VLC, go to Tools > Preferences > Video. Change the Output dropdown from Automatic to Direct3D11 video output or OpenGL, then restart VLC.
  • Audio Not Heard on Stream: In the OBS Audio Mixer, click the three dots next to your VLC source, open Advanced Audio Properties, and set Audio Monitoring to Monitor and Output.
