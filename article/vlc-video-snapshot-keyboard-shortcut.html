VLC Video Snapshot Keyboard Shortcut

Capturing high-resolution still frames from a playing video is a fast and seamless process using VLC media player. This guide covers the exact default keyboard shortcuts used to take instant video snapshots across Windows, macOS, and Linux operating systems. You will also learn where your saved images are automatically stored on your computer and how to customize the snapshot shortcut keys and output directories to match your personal workflow.

Default VLC Snapshot Shortcuts by Operating System

To capture a frame instantly while a video is playing or paused, press the corresponding key combination for your platform:

  • Windows: Press Shift + S
  • Linux: Press Shift + S
  • macOS: Press Command + Option + S (or Cmd + Alt + S)

When pressed, VLC will briefly display a small preview of the captured frame in the top-left corner along with the file path indicating the image has been saved.

Where VLC Stores Video Snapshots

By default, VLC saves snapshots in your operating system's standard image directory in either PNG or JPG format:

  • Windows: C:\Users\<Username>\Pictures
  • macOS: /Users/<Username>/Pictures
  • Linux: ~/Pictures

How to Change the Shortcut or Save Location

If you prefer a different shortcut key or want your snapshots saved to a dedicated folder, you can modify VLC’s settings:

  1. Open VLC and navigate to Tools > Preferences (or press Ctrl + P on Windows/Linux, Cmd + , on macOS).
  2. To change the save location and file format, select the Video tab. Scroll to the Video snapshots section to select a new folder destination, change the file prefix, or switch between PNG, JPG, and TIFF formats.
  3. To change the shortcut itself, select the Hotkeys tab, scroll down to Take video snapshot, double-click the assigned key combination, press your preferred key, and click Save.
