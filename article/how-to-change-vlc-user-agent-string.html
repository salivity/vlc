How to Change VLC User Agent String

VLC Media Player identifies itself to web servers using a default user agent string whenever it streams network media or requests online resources. Modifying this string is often necessary to bypass server-side blocks, mimic standard web browsers, or troubleshoot media streams that restrict playback based on the client application. This guide explains how to change the VLC HTTP user agent through both the graphical user interface and the command-line interface.

Method 1: Change the User Agent via VLC Preferences

You can permanently change the default user agent inside VLC's advanced settings:

  1. Open VLC Media Player.
  2. In the top menu bar, click on Tools and select Preferences (or press Ctrl + P on Windows/Linux, Cmd + , on macOS).
  3. At the bottom-left corner of the Preferences window, locate the Show settings section and select the All radio button to unlock the advanced settings.
  4. In the left-hand navigation tree, expand Input / Codecs.
  5. Expand Access modules and click on HTTP(S).
  6. In the right-hand panel, find the field labeled HTTP user agent.
  7. Enter your desired custom user agent string into the text box (for example, a modern browser string like Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36).
  8. Click Save at the bottom right.
  9. Restart VLC Media Player for the changes to take full effect.

Method 2: Change the User Agent via Command Line

If you launch VLC from a terminal, command prompt, or script, you can temporarily override the user agent without modifying your saved preferences.

Run VLC with the --http-user-agent flag followed by your custom string:

vlc --http-user-agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64)" "http://example.com/stream.m3u8"

Replace the URL with your desired network stream link. VLC will execute that specific session using the defined user agent and revert to default once the session closes.
