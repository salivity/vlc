How to Receive Multicast RTP Streams in VLC

Setting up VLC Media Player to receive a multicast Real-time Transport Protocol (RTP) stream over a local network is a simple process that requires the stream’s multicast IP address and port number. This guide outlines the exact network syntax needed in VLC, step-by-step instructions to open the stream, and key network configurations—such as firewall and interface settings—required to ensure the broadcast displays smoothly without packet drops.

Prerequisites

Before starting, ensure you have:

  • The multicast IP address assigned to the stream (typically in the range 224.0.0.0 to 239.255.255.255).
  • The destination port number (commonly 5004 or another specified UDP port).
  • Both the streaming server and the client machine connected to the same local subnet, with network switches configured to allow multicast traffic (IGMP enabled).

Step-by-Step VLC Setup

  1. Open VLC Media Player.

  2. Access Network Stream: Click on Media in the top menu bar and select Open Network Stream... (or press Ctrl + N on Windows/Linux, Cmd + N on macOS).

  3. Enter the Network URL: In the "Please enter a network URL" field, enter the multicast address using the following format:

    rtp://@[Multicast_IP]:[Port]

    Example: rtp://@239.255.1.100:5004

    (Note: The @ symbol instructs VLC to bind to the local port and listen for incoming multicast packets targeting that group address across all network interfaces.)

  4. Start Playback: Click the Play button at the bottom. VLC will join the multicast group via IGMP and begin decoding incoming packets.

Binding VLC to a Specific Network Interface

If your computer has multiple active network interfaces (such as Wi-Fi and a wired Ethernet connection), VLC may attempt to listen on the wrong network adapter. To bind VLC to the correct adapter:

  1. Navigate to Tools > Preferences (or press Ctrl + P).
  2. At the bottom-left corner under "Show settings", select All.
  3. In the left sidebar, expand Input / Codecs and click on Demuxers.
  4. Expand Demuxers and select RTP/RTSP.
  5. Locate the Multicast interface field and enter the local IPv4 address of the specific network adapter connected to the stream's network.
  6. Click Save and restart VLC.

Troubleshooting Multicast Playback

  • Local Firewall: Multicast traffic is frequently blocked by host firewalls. Ensure that UDP traffic on the specified port is allowed through the firewall, or temporarily add an inbound exception rule for the VLC application executable.
  • IGMP Snooping: If video does not appear, managed network switches between the sender and receiver may be blocking traffic via IGMP Snooping. Ensure an active IGMP querier exists on the local network or that IGMP Snooping is disabled on the switch for testing.
  • Verify Traffic with Wireshark: If VLC displays a black screen or fails to connect, run a packet capture tool like Wireshark on the receiving machine and filter by rtp or udp.port == [your_port] to verify that packets are physically reaching your network interface card.
