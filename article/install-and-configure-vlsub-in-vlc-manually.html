Install and Configure VLSub in VLC Manually

This guide explains how to manually install and configure the VLSub extension for VLC Media Player across Windows, macOS, and Linux. VLSub is a dedicated extension that searches and downloads subtitles directly from OpenSubtitles.org. While recent versions of VLC include VLSub by default, manually installing or updating the script ensures you have the latest, working version if the pre-installed version fails.

Step 1: Download the VLSub Script

  1. Download the latest vlsub.lua file from the official VideoLAN Add-ons repository or the project's GitHub repository.
  2. If the file downloads as an archive (ZIP), extract it to locate the single file named vlsub.lua.

Step 2: Move the Script to the VLC Extensions Directory

You must place vlsub.lua into the specific extensions folder for your operating system. If the lua or extensions folders do not exist, create them manually.

Windows

  • Current User (Recommended):
    Press Win + R, paste %APPDATA%\vlc\lua\extensions\, and press Enter. Move vlsub.lua into this folder.
  • All Users:
    Navigate to C:\Program Files\VideoLAN\VLC\lua\extensions\ (or Program Files (x86) on 32-bit installations) and paste the file there.

macOS

  1. Open Finder, click Go in the top menu bar, and select Go to Folder....
  2. Enter ~/Library/Application Support/org.videolan.vlc/lua/extensions/ and press Enter.
  3. Place vlsub.lua into this directory.

Linux

  1. Open your terminal or file manager.
  2. Navigate to ~/.local/share/vlc/lua/extensions/ (or create it using mkdir -p ~/.local/share/vlc/lua/extensions/).
  3. Copy vlsub.lua into this directory.

Step 3: Configure VLSub in VLC

  1. Restart VLC Media Player if it was open during the installation.
  2. Open VLC and start playing any video file.
  3. Click the View menu at the top, then select VLSub.
  4. In the VLSub window, click the Show config button to open settings:
    • Subtitle language: Select your preferred primary language for subtitles.
    • OpenSubtitles account: Enter your OpenSubtitles username and password if required by the API.
  5. Click Save config to apply the changes.

Step 4: Search and Download Subtitles

  1. With your video playing or paused, open View > VLSub.
  2. Choose one of the search methods:
    • Search by hash: Generates a unique fingerprint of your video file to find exact synchronized matches.
    • Search by name: Searches using the title of the video file, allowing you to manually enter or correct the title and season/episode details.
  3. Select the best match from the results list.
  4. Click Download selection. The subtitle will automatically download to the same directory as your video file and load into the current playback session.
