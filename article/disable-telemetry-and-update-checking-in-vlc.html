Disable Telemetry and Update Checking in VLC

VLC Media Player occasionally communicates over the internet to check for application updates and retrieve online metadata, such as album art and track information. While VLC is open-source and respects user privacy, these outbound requests transmit minimal device and media details across the network. This guide outlines the straightforward steps to disable automatic update checking and network metadata retrieval in VLC to ensure complete offline privacy.

Disable Update Checking and Network Access

  1. Open VLC Media Player.
  2. In the top menu, navigate to Tools and select Preferences (or press Ctrl + P on Windows/Linux, or Cmd + , on macOS).
  3. Ensure the Interface tab is selected at the top of the window, and that the settings view at the bottom-left is set to Simple.
  4. Scroll down to the Privacy / Network Interaction section.
  5. Uncheck the box labeled Activate automatic update checking.
  6. Uncheck the box labeled Allow metadata network access to prevent VLC from querying external servers for track details and album artwork.
  7. Click the Save button in the lower-right corner of the window.

Verify Initial Privacy Prompt Settings

If you are setting up VLC Media Player for the first time, you can prevent these network connections immediately upon installation:

  1. Launch VLC Media Player.
  2. When the Privacy and Network Access Policy window appears during the first startup, uncheck both Allow metadata network access and Regularly check for VLC updates.
  3. Click Continue to save the preferences.

Restart VLC Media Player after making these adjustments. VLC will now run entirely locally without initiating outbound connections for update checks or media information queries.
