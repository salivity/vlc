Can VLC Stream Media from an SFTP Server?

VLC Media Player can stream audio and video files directly from a secure SFTP (SSH File Transfer Protocol) server without requiring you to download the entire file first. This guide explains how VLC natively handles the SFTP protocol, the exact network URL syntax needed to establish a connection, how authentication is handled, and configuration tips to ensure smooth, buffer-free playback over remote networks.

Direct SFTP Streaming in VLC

VLC includes built-in support for SFTP through integrated SSH libraries. This allows the player to read media streams over an encrypted SSH tunnel in real-time, functioning much like standard HTTP or RTSP streams.

How to Open an SFTP Stream

To stream a file directly from your SFTP server, follow these steps:

  1. Open VLC Media Player.
  2. Click on Media in the top menu bar (or File on macOS) and select Open Network Stream (shortcut: Ctrl + N on Windows/Linux, Cmd + N on macOS).
  3. In the URL field, enter the complete SFTP path using this syntax: sftp://username:password@hostname:port/path/to/media/file.mp4
  4. Click Play.

URL Syntax Breakdown

  • Protocol: Must begin with sftp://.
  • Credentials: username:password@ is optional in the URL itself. If you omit the password (e.g., sftp://username@hostname/...), VLC will prompt you with a dialog box to enter your password securely.
  • Host and Port: Specify the domain or IP address. If your SSH daemon uses the standard port 22, you can omit the :port designation.
  • File Path: Provide the absolute path from the root directory or the relative path from the user's home directory.

Authentication Methods and Limitations

While VLC easily handles standard username and password authentication via the network stream dialog, it does not provide native GUI options to supply SSH private keys (e.g., id_rsa or id_ed25519). If your SFTP server strictly enforces public key authentication and disables password logins, you will need to mount the SFTP server locally using tools like SSHFS, WinFsp, or Cyberduck, and then open the mounted file inside VLC as a local file.

Optimizing Playback and Buffering

Streaming large, high-bitrate video files over an encrypted connection requires stable network throughput. If you experience stuttering or buffering delays:

  1. In the Open Network Stream window, check the Show more options box at the bottom.
  2. Increase the Caching value from the default (typically 1000 ms or 1200 ms) to 3000 ms to 5000 ms.
  3. Alternatively, navigate to Tools > Preferences, set Show settings to All, select Input / Codecs on the left panel, scroll down to Advanced, and increase the Network caching (ms) value permanently.
