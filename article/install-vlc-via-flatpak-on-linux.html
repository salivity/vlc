Install VLC via Flatpak on Linux

Yes, you can install VLC Media Player as a Flatpak package on almost any Linux distribution. This article provides a straightforward guide on setting up the Flathub repository, installing the official VLC Flatpak, running the application, and managing updates or removals.

Prerequisites

Before installing VLC, ensure that Flatpak is installed on your system. Most modern distributions like Fedora, Linux Mint, and Pop!_OS come with Flatpak pre-installed. If your system lacks Flatpak, install it using your distribution's default package manager:

  • Ubuntu/Debian: sudo apt install flatpak
  • Fedora: sudo dnf install flatpak
  • Arch Linux: sudo pacman -S flatpak

Step 1: Add the Flathub Repository

VLC is hosted on Flathub, the primary repository for Flatpak applications. Enable Flathub by executing the following command in your terminal:

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

After adding the repository, restart your system or log out and back in to ensure your desktop environment updates its application paths.

Step 2: Install VLC

Once Flathub is enabled, you can install the official VLC package using the terminal:

flatpak install flathub org.videolan.VLC

When prompted to confirm the installation and download necessary runtimes, press y and then Enter. Flatpak will download and configure the latest stable version of VLC and its sandboxed dependencies.

Step 3: Launch VLC

After the installation finishes, you can launch VLC in two ways:

  1. Desktop Menu: Open your desktop application launcher, search for "VLC", and click the icon.
  2. Terminal: Run the following command:
flatpak run org.videolan.VLC

Managing the VLC Flatpak

To keep VLC updated along with your other Flatpak applications, run:

flatpak update

If you ever need to uninstall the VLC Flatpak package, use this command:

flatpak uninstall org.videolan.VLC
