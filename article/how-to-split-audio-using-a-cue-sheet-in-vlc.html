How to Split Audio Using a CUE Sheet in VLC

Splitting a single large audio file into individual tracks using a CUE sheet is a standard process for managing album rips in formats such as FLAC, WAV, or MP3. While VLC Media Player does not feature an automated batch-splitting utility, it natively reads CUE sheets to divide the master audio file into distinct playlist chapters. This guide explains how to properly load your CUE sheet into VLC and export individual audio tracks to separate files.

Step 1: Prepare the CUE and Audio Files

Before opening VLC, ensure that the CUE file correctly references your audio file:

  1. Place both the audio file (e.g., album.flac) and the .cue file in the same directory.
  2. Open the .cue file with a plain text editor such as Notepad or TextEdit.
  3. Locate the FILE line near the top (e.g., FILE "album.flac" WAVE).
  4. Verify that the file name and extension inside the quotation marks match your audio file's exact name. If they do not match, update the text and save the file.

Step 2: Load the CUE Sheet into VLC

  1. Launch VLC Media Player.
  2. Click Media on the top menu bar and select Open File... (or press Ctrl + O on Windows / Cmd + O on macOS).
  3. Navigate to your folder, select the .cue file (not the large audio file), and click Open.
  4. Open the playlist view by clicking View > Playlist (or pressing Ctrl + L / Cmd + L).

VLC will parse the CUE sheet and display every song as an individual track with its corresponding title, artist, and duration, rather than one single continuous track.

Step 3: Extract Individual Tracks to Separate Files

VLC allows you to save individual tracks parsed from the CUE sheet using either the Advanced Recording feature or the Convert menu.

Method A: Using VLC Advanced Controls (Quickest for Individual Songs)

  1. Go to View on the top menu bar and check Advanced Controls. This displays a row of extra buttons, including a red Record button, above the standard playback controls.
  2. In the playlist, double-click the track you want to extract.
  3. As the track starts playing, click the red Record button.
  4. Let the track play to the end (or skip directly to the end of the track time) and click the Record button again to stop recording.
  5. The extracted audio segment will automatically save to your system's default Music (or Videos) directory.

Method B: Using the Convert/Save Feature

  1. Click Media > Convert / Save... (or press Ctrl + R).
  2. Click Add... and select the main audio file.
  3. Check the Show more options checkbox at the bottom of the window.
  4. Check the CUE sheet for the exact start and end timestamps of the track you wish to extract.
  5. Enter the starting timestamp into the Start Time field and the ending timestamp into the Stop Time field.
  6. Click Convert / Save.
  7. Under Profile, choose your preferred output format (such as Audio - FLAC or Audio - MP3).
  8. Click Browse next to Destination file, choose where to save the track, and give it a name.
  9. Click Start to process and save the file. Repeat this process for each track listed in the CUE sheet.
