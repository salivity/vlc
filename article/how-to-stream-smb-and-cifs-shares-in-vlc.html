How to Stream SMB and CIFS Shares in VLC

VLC Media Player includes built-in support for SMB (Server Message Block) and CIFS protocols, allowing you to stream videos and music directly from local network storage, such as a NAS or shared PC folder, without downloading the files first. This guide provides step-by-step instructions on how to discover network shares automatically, connect to them manually, and configure settings across desktop and mobile devices.

Accessing SMB Shares on Desktop (Windows and macOS)

Method 1: Automatic Discovery

  1. Open VLC Media Player.
  2. Open the Playlist view by pressing Ctrl + L (Windows) or Cmd + Shift + P (macOS), or by selecting View > Playlist.
  3. In the left-hand sidebar, scroll to the Local Network section.
  4. Click on Universal Plug 'n' Play or Windows Shares (SMB).
  5. Wait a few moments for your network devices to appear. Double-click your server or computer name, enter your network username and password if prompted, and browse to your media folder.

Method 2: Direct Network Stream (Manual Connection)

If your share does not appear automatically, you can connect directly using its local IP address or hostname:

  1. Click Media (or File on macOS) in the top menu bar.
  2. Select Open Network Stream... (shortcut: Ctrl + N on Windows, Cmd + N on macOS).
  3. In the URL field, enter the path using the SMB protocol format:
    smb://[IP-ADDRESS]/[SHARE-NAME]
    (Example: smb://192.168.1.100/Media)
  4. If your share requires authentication, you can format the URL with credentials:
    smb://username:password@[IP-ADDRESS]/[SHARE-NAME]
  5. Click Play to start browsing or streaming.

Accessing SMB Shares on Mobile (Android and iOS)

  1. Open the VLC app on your smartphone or tablet.
  2. Tap the Browse tab located in the bottom navigation bar.
  3. Under the Local Network header, wait for your network drives to populate.
  4. Tap your server name to connect. If credentials are required, enter your username and password when prompted.

Adding a Server Manually on Mobile

If the share does not show up automatically:

  1. In the Browse tab, tap the + (plus) icon or Add server.
  2. Select SMB from the protocol dropdown list.
  3. Enter the server's local IP address (e.g., 192.168.1.50).
  4. Enter the shared folder name, along with your username and password.
  5. Save the connection to access the share at any time from your list of servers.

Troubleshooting Common SMB Issues in VLC

  • SMB Protocol Version: Modern operating systems disable SMBv1 for security reasons. If VLC cannot connect, navigate to Tools > Preferences (set to All at the bottom left), go to Input / Codecs > Access modules > SMB, and set the SMB version to SMBv2 or SMBv3.
  • Firewall Blocking: Ensure that ports 445 and 139 are not blocked by the firewall on the host machine hosting the files.
  • Credentials: If you do not use a password on your host machine, Windows may block remote access by default. Ensure the sharing computer has password-protected sharing configured properly.
