Fix VLC Audio Skipping by Adjusting Buffer Size

Audio stuttering, crackling, or skipping in VLC Media Player is typically caused by buffer underruns, which occur when the player processes data faster than it can read or decode it. Increasing the internal caching and buffer size provides VLC with a larger temporary reserve of audio frames, smoothing out playback hiccups caused by high-bitrate media, slow storage drives, or background system tasks. Below are the steps to adjust both file caching and audio output module buffers in VLC.

Method 1: Increase File Caching Buffer

Increasing the general file caching buffer is the most effective way to eliminate skips during local file playback.

  1. Open VLC Media Player.
  2. Click Tools in the top menu bar and select Preferences (or press Ctrl + P on Windows / Cmd + , on macOS).
  3. At the bottom-left of the window, locate the Show settings section and toggle the radio button from Simple to All.
  4. In the left panel, click on Input / Codecs.
  5. Scroll down to the Advanced section on the right side.
  6. Locate File caching (ms). The default value is typically set between 300 ms and 1000 ms.
  7. Increase this value to 1500 or 2000 ms (values up to 3000 ms can be used for very high-bitrate or 4K files).
  8. If you experience skipping while playing files over a local network or stream, also increase Network caching (ms) to 2000 ms or higher.
  9. Click Save and restart VLC for the changes to take effect.

Method 2: Adjust the Audio Output Buffer

If adjusting the file caching buffer does not fully resolve the stutter, adjust the dedicated buffer within your audio output module.

  1. Open VLC and navigate back to Tools > Preferences.
  2. Select All under the Show settings option at the bottom left.
  3. In the left sidebar, expand the Audio category by clicking the arrow next to it, then click on Output modules.
  4. If an output module is specifically selected (such as DirectX audio output or WaveOut on Windows), click on that specific module in the sidebar.
  5. Locate the setting labeled Audio output buffer length in ms (or Buffer length).
  6. Increase the default value (often set to 500 ms) to 1000 ms or 1500 ms.
  7. Click Save and restart VLC.

Additional Troubleshooting

If audio skipping persists after increasing these buffers:

  • Disable Hardware Acceleration: Go to Tools > Preferences (Simple mode) > Input / Codecs, and set Hardware-accelerated decoding to Disable.
  • Change Audio Output Module: Go to Tools > Preferences > Audio, and change the Output module dropdown from Automatic to DirectX or WaveOut (on Windows) to test if a different driver interface resolves the conflict.
