Launch and Control VLC Using Command Line

This guide explains how to open VLC Media Player, initiate media playback, and control playback options entirely through the command-line interface (CLI). You will learn the basic commands for launching files across different operating systems, how to enable VLC's built-in interactive console control, and how to operate VLC in headless mode for automation and scripting.

Locating the VLC Executable

Before running commands, ensure your terminal recognizes VLC.

  • Linux: VLC is typically in your PATH. Simply run vlc.
  • macOS: Use the full path: /Applications/VLC.app/Contents/MacOS/VLC. You can create an alias by adding alias vlc='/Applications/VLC.app/Contents/MacOS/VLC' to your ~/.zshrc or ~/.bash_profile.
  • Windows: Navigate to the installation directory (usually C:\Program Files\VideoLAN\VLC) or run vlc directly if added to system Environment Variables.

Basic Launch and Playback Commands

To open a media file directly from the terminal:

vlc path/to/video.mp4

To stream a network URL directly:

vlc https://example.com/stream.m3u8

Common Launch Flags

You can customize how the player opens by appending arguments:

  • Fullscreen: vlc --fullscreen video.mp4
  • Loop a single file: vlc --loop video.mp4
  • Repeat an entire playlist: vlc --repeat video1.mp4 video2.mp4
  • Play without video (audio only): vlc --no-video audio.mp3
  • Close VLC when media ends: vlc --play-and-exit video.mp4

Interactive Terminal Control (rc Interface)

VLC includes an "old remote control" (rc) interface that allows you to control media using text commands directly in your terminal.

To launch VLC with this interface active in the terminal alongside the GUI:

vlc --extraintf rc video.mp4

To run VLC purely inside the terminal without the graphical window (headless/console only):

vlc -I rc video.mp4

(On Linux, you can also use the shorthand command cvlc video.mp4, which automatically disables the GUI).

Key Interactive Commands

Once the rc prompt (>) appears, you can type the following commands and press Enter:

  • pause — Toggles pause and resume.
  • stop — Stops playback.
  • play — Resumes or starts playback.
  • volup [steps] — Increases the volume (e.g., volup 2).
  • voldown [steps] — Decreases the volume.
  • seek [seconds] — Jumps to a specific timestamp (e.g., seek 60 moves to the 1-minute mark).
  • faster / slower — Adjusts playback speed.
  • info — Displays metadata about the currently playing stream.
  • quit — Exits VLC completely.

Controlling VLC over a Network Socket

For scripting and automation, you can bind the command-line interface to a TCP socket so external scripts (like Python or Bash) can send commands.

Launch VLC and bind the control interface to a local port:

vlc -I rc --rc-host 127.0.0.1:4212 video.mp4

You can now connect to VLC and send commands using tools like Netcat or Telnet from another terminal window or automated script:

nc 127.0.0.1 4212

Once connected, any valid rc command (such as pause, stop, or quit) sent over the socket will control the player in real time.
