Does VLC Support Picture in Picture on Windows?

VLC Media Player does not offer a dedicated, native Windows Picture-in-Picture (Compact Overlay) feature in its classic desktop application. However, users can easily replicate the exact behavior and appearance of a Picture-in-Picture window by using VLC's built-in "Always on top" setting combined with minimal view controls.

Why VLC Lacks Native Picture-in-Picture

Modern Windows operating systems include a native Compact Overlay API that allows apps like Microsoft Movies & TV, Edge, and Chrome to create true Picture-in-Picture pop-outs. The standard desktop version of VLC (Win32) does not utilize this specific API. As a result, there is no single-click native PiP button in the media control bar.

How to Enable Picture-in-Picture Mode in VLC

You can recreate a Picture-in-Picture experience manually in just a few steps:

  1. Keep the Player on Top:

    • Open VLC Media Player and start playing your video.
    • Click on the View menu at the top.
    • Select Always on top. This prevents other open windows from covering the VLC playback window.

  2. Hide the Interface:

    • Press Ctrl + H on your keyboard to toggle the "Minimal View." This hides the playlist, status bar, and toolbar controls, leaving only the video frame visible.
    • Alternatively, you can go to Tools > Preferences > Interface, uncheck "Integrate video in interface," and save to separate the video window completely from the controls.

  3. Resize and Reposition:

    • Click and drag any corner of the VLC window to shrink it to your desired size.
    • Drag the window to the bottom-right corner (or any preferred area) of your monitor.

Restoring the Normal View

When you want to return VLC to its default state:

  • Press Ctrl + H again to restore standard controls and borders.
  • Click View and uncheck Always on top so the window behaves normally within the Windows desktop environment.
